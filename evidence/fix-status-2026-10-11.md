## 已修复

| 核查问题 | 当前实现 |
|---|---|
| 会话请求发往配置服务 | 配置与运行客户端分开；会话创建使用 runtime 5014。 |
| 空 Metadata 被平台拒绝 | 普通请求省略该字段；伪造 Metadata 改为独立拒绝测试。 |
| 原生顶层 reasoning_effort 不兼容 | 关闭平台思考，通过三个 Agent 的提供方自定义参数传递 none；已核对固定上游参数处理，实际平台推理仍待验收。 |
| 子 Agent 与最终结果判定不完整 | 核对真实 Agent ID、中文显示名、调用 ID、深度和时序；最终字段及工作人员缺失项必须对应工具审计。 |
| 新会话、预热及参数没有成为选型门槛 | 要求独立会话、预热成功、模型参数正确且实际仅加载当前模型；异常保存失败及部分证据。 |
| SQLite 锁超时未重试 | 将真实 SQLITE_BUSY/LOCKED 转换为技术超时，验证最多两次尝试。 |
| 进度状态写死 | 根据实时环境探测、原生结果、UI 和故障证据生成状态；不接受缺失、旧轮次或变更后的 UI 文件。 |
| 故障及 UI 验收没有闭环入口 | 增加原生负向测试及用户确认 UI 证据脚本，绑定同轮核心结果；未执行不会标为通过。 |
| 首次安装没有自动设置权限 | 启动入口初始化私有目录；Windows DACL 只允许当前用户和 SYSTEM，新文件继承。 |
| Compose 变量默认值被端口改写破坏 | 修复端口解析并恢复已识别的旧错误改写，保持 loopback 绑定。 |
| 账号操作没有用户接手边界 | 从固定官方脚本生成服务部署副本，跳过其自动注册超级管理员；账号初始化和 UI 登录由用户启动。 |
| 旧 MinIO 镜像不可拉取 | 从固定官方服务端与客户端源码构建本地镜像，验证版本和提交，记录实际镜像 ID 后显式配置。 |
| PowerShell 将原生 stderr 进度判成失败 | 使用当前镜像源参数并根据真实退出码判断部署成败。 |
| 新版 FastAPI 自动遥测导致应用启动失败 | Nexent 关闭遥测时，同步关闭 traces/metrics/logs 自动导出器，保留 SDK 使用的原协议设置。 |
| 前端语言重定向被误判为服务未就绪 | 就绪探测跟随语言重定向，实际前端返回 200。 |
