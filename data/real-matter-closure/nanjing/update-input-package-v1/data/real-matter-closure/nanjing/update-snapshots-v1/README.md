# 南京真实原件更新输入快照

三组完整快照都保留官方HTML原件、全部正文、原文引用及文件清单。四来源组另含已归档的扫描公报与AI视觉核对记录。OCR仍待队友处理。

| 目录 | 来源/规则/正文段落 | 用途 |
| --- | --- | --- |
| `registered-three` | 3 / 12 / 49 | 受控初始登记的南京来源子集，来源检查时间保留原值 |
| `observed-three` | 3 / 12 / 49 | 本轮HTTP复查的三份原件，带实际采集回执；正文与元数据无变化 |
| `registered-four` | 4 / 16 / 142 | 加入本轮实际取回的全国法律HTML来源；同一份输入分别验证种子与演化本体 |

本轮四份网页正文和原始字节均未观测到政府网站变更。这是实际原件进入登记范围的更新试验；三来源组是受控的知识库初始范围，不能作为政府网站历史政策版本。公布、生效和抓取日期分别保存，规则始终待人工业务复核。

在仓库根目录或完整输入包中执行：

```powershell
python scripts/verify_matter_update_inputs.py
```

该命令只读核对已存原件、引用和开发推导：三来源+种子、四来源+种子均缺完整证明；四来源+演化本体得到4条替代证据路径，支持1个候选结论。法律页面同时保留修正决定与合并条文，两处位置不算独立法规或独立评测题。

离线输入校验不检查当前官网适用性，也不更新来源时间、启动服务或发布业务知识。运行真实活动时保留24小时新鲜度检查；过期后须实际重新采集，不能编辑`checked_at`恢复。
