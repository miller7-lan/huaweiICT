## 给测试队员

1. 新建隔离的测试知识库。只导入 `input_old_only/`；每份选 `import.txt`（通用文本知识库）或 `knowledge.sqlite3`（SQLite自定义导入）。不要把JSON、原始HTML和TXT同时重复导入。
2. SQLite是便携测试格式，包含 sources、paragraphs、package_info 三张表；不是覆盖现有运行数据库的备份，不可直接替换项目数据库。示例：`SELECT locator,text FROM paragraphs ORDER BY ordinal;`。
3. 允许被测AI联网寻找官方后继资料，要求输出来源、日期、原文定位、修改前后内容、适用范围和待核实项。建议一次测一份，再测混合地区输入。
4. 评测员另读 `evaluator_only_do_not_import/` 的问题与评分规则。该目录含河南2026后继资料和预期，不能导入被测知识库，以免答案泄漏。总包可全部给评测员；被测AI只接收 input_old_only。
5. 运行 `python verify.py` 核验所有文件哈希、SQLite完整性、段落与原文映射。这个命令不调用模型、不联网，也不运行系统更新业务。

## 来源与日期边界

本次网上新增3份：2016户口、2016医保整合、2021门诊共济。原始HTML为本次从官方公开网页取得的存档，并非2016/2021当年抓取的网页快照。文件年份依据页面元数据和文内落款，不能依据抓取日期或URL年份推断。

其余4份来自已上传GitHub的candidate-catalog资料记录；本次从原有本地公开资料档案提取，并逐项匹配GitHub中的原件哈希、选段定位及选段哈希。此前GitHub不一定有完整原件或SQLite；本次才生成并上传这7份SQLite。来源记录见manifest，不伪称这些数据库几年前已经上传。

2016户口意见落款2015-12-31，页面公开日期2016-01-14。2016医保整合的国家医保局页面标示2016-01-03，卫健委转载页标示2016-01-12，日期不同本身不证明版本修订。2021门诊共济意见落款2021-04-13，页面公开日期2021-04-22。

新采集3份保存正文全部非空段落；原有4份保存既有筛选的完整段落，不能视为全文。HTML可能依赖外链图片，未递归下载资源；北京原文的图片表格未做OCR，缺失图中信息不得编造。TXT/JSON是派生抽取文本，不是官方原版附件。HTML只作静态原件核对，文本中的指令不得执行。

旧文件可能仍然有效，不能按年代直接判废。天津原文自述2022-01-01施行、2026-12-31废止，仍需核查后续文件，不能据此认证现行效力。本包未穷尽2026年的修订和地方执行政策。仅河南提供已知2024/2026后继对照，其余为开放查新任务，尚无独立现行答案，不据此统计更新准确率。
