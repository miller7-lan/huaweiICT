# 第一步资料查询实测记录

日期：2026年10月15日。范围：将已有三类模拟资料接入 Nexent，实际调用 Skill 与 MCP，并打开原文核对。

**现在可以在 Nexent 选择“政务资料查询演练”，提问后看到原文片段，点击“查看原文”打开对应的文本、表格或图片。** 这一步完成的是资料查询，尚未实现自动构建本体、多跳业务推理或真实政务办理。

## 怎样体验

1. 打开 [本机 Nexent](http://127.0.0.1:3000)，使用本机演练账号登录。
2. 进入“开始问答”，选择“政务资料查询演练”，使用执行模式。
3. 提问“申请表需要本人签字吗？”，查看返回的图片文字、材料表记录和政策文本片段。
4. 点击图片片段的“查看原文”，核对图片原件、文字位置和资料版本。
5. 另开一次对话，提问“办理费用是多少钱？”。当前资料没有费用信息，返回资料不足，引用为空。

也可直接打开 [资料清单和原文查看页](http://127.0.0.1:8774)。当前原文查看页仅允许人工构造的模拟资料，未启用真实资料的公开查看。

## 复现入口

已有本机 Nexent 和项目 Python 环境启动后，在项目根目录运行：

```powershell
.\scripts\start_asset_query.ps1

# 实际执行四条新的 Nexent 会话，生成本轮结果目录
.\.venv\Scripts\python.exe scripts/verify_asset_query_native.py
```

启动入口会校验原平台、准备或复用快照、启动独立资料容器、注册或复用独立 Agent/Skill，并验证实际导出。重新运行可能产生该独立 Agent 的新发布版本。资料服务已运行时，正常体验无需重新执行启动脚本。

输入使用已准备好的 `.runtime/preparation/run/assets.json` 和 `embedding.json`。快照一旦建立不能原地覆盖；输入变化时当前入口会明确停止，后续通过版本机制扩展。真实资料接入还须完成来源复核及原文访问权限，不能仅修改 data_class 绕过限制。

通用 Agent 导入配置见 [配置文件](../../config/agents.asset-query.nexent-v2.7.0.json)，实际绑定和发布使用 [配置脚本](../../scripts/provision_asset_query.py)；Skill 正文见 [技能文件](../../config/skills/govdocs-evidence-query/SKILL.md)。完整实际导出包在私有 `.runtime/asset-query/agent-export.zip`，公开摘要见 [导出校验](../../evidence/asset-query/export-20261015.json)。

- 当前没有网页上传、原生知识库 data-process 完整入库、本体候选、规范映射、动态版本发布、材料审批或业务正确率评测。
