## 复核包如何使用和停止沿用

`scripts/export_knowledge_review_packet.py`现在把注释放在独立的`source_scope_notes`中；原复核决定栏仍为空，已记录资料复核保持独立。公开[复核准备摘要](../evidence/knowledge-update/review-readiness.json)显示1份注释绑定有效、0份被收起、业务批准为false。来源原件或最新修订、正文、元数据、状态、试点范围或定位变化后，相关整份分析会停止带入复核包，并显示原因；不会仅凭旧原件仍存在而继续沿用旧判断。

绑定有效只证明注释指向当前归档及指定文字，不证明分析必然正确、现行效力、网办资格或参考独立性。注释作为仓库文件随Git共享，不写入SQLite或访客检索/发布路径。缺少注释文件时保持旧导出能力；损坏或过期内容不冒充已绑定分析。
