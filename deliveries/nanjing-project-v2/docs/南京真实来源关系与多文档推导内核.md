# 南京真实来源关系候选与跨文档推导内核

2026-10-19。在已发布的[来源与规则包](南京真实事项来源与规则复核包.md)上实现纯本地、可追溯的关系候选和声明式连接推导。真实原文与未发布开发推导分开标识，不修改旧工作台的模拟限制，不调用模型、不发布正式知识。

## 本次实际实现

- 用两个透明种子模板扫描真实原文段落，自动产生3条带偏移和原件哈希的关系候选：两份南京资料各一条“旧证未超期等待期间可用”，法律第十一条一条“领取新证时交回原证”。提取不读取16张手工规则卡的结论字段。
- 种子本体含证件、阶段类型及“办理期间可用”关系。预览v2新增“领取阶段交回”关系及可执行组合规则。
- 推导器统一变量，连接同一证件的可用阶段、前后阶段顺序及后阶段交回义务，产生“使用至交回阶段”的时序关系。输出保存所有输入边、来源、原文、定位、上下文哈希和所用规则；没有预填问题答案或来源编号。
- 阶段顺序是明确登记的业务流程种子公理，不伪装为法律原文；推导保留“旧证未超期”的条件。当前回答只能是DRAFT_PROOF_READY，不是正式业务承诺。

| 检查 | 结果 |
