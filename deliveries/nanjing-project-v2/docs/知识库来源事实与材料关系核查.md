## 材料关系保留了哪些差别

[12项事实及全部定位](../evaluation/knowledge/source-fact-assessments.json)中包含7项材料/条件观察：

- 国家第78条将申领、换领、补领并列后规定交验户口簿，不能把这段原文概括成只针对首次申领。
- 河南第159条区分申请领取、申请换领、申请补领：前两者分别写户口簿、居民身份证；补领另列有效证件之一。补领列表不能转用为到期换领替代清单。
- 国家第12条与河南第7条均有材料共享确认前提；两份对免纸质的具体表述分别保留，不能概括成任何情况都不必提供材料。
- 河南第7条另有“办理户口业务”中的双方关系证明规则。其业务与证明目的不能扩展为所有身份证明的通用替代办法。

这些是各份原文内部的字词、分支和条件核对。国家第78条、省第159条、区级材料列表及二七区当前执行之间的关系仍未裁定，未自动选择一份覆盖其他出处。KQ01、KQ02、KQ09、KQ19四道开发参考题现同时保留国家和省级条款，前两题的参考措辞也已补全。参考集仍为30题AI开发草案。

每项文字证据均绑定原修订、原件SHA256、定位、字符起止和引文指纹；页面日期观察绑定原始页面标注字段及其指纹。新修订指向同一原件、同一条文内容，旧修订不覆盖。所有内容见上述JSON的字段差异和前后修订ID。
