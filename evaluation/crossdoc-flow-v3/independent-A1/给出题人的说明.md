# 出题说明（给独立出题人）

感谢你帮忙出题。这份说明是你唯一需要读的文字材料，读完就可以开始。预计用时 **5—6 小时**，可以分几次完成。

## 一、你在做什么

我们做了一个“政务资料问答”程序，要用一批**它从没见过的题目**来测它答得对不对、该不回答时能不能不回答。你出的题和参考答案，会交给两位评审，用来给几种问答方法打分。

为了让测试公平，题目必须由不了解这个程序的人来出。所以：

- **不要**打开项目的代码仓库、文档、聊天记录，也不要问组员这个程序是怎么工作的；
- **不要**看以前出过的题、程序的回答或任何测试结果；
- **不要**上网查资料，只依据我们给你的七份资料原文；
- 出题期间和交回之前，**不要**和组员讨论题目内容（问“格式怎么填”可以，问陈）。

如果你用了 AI 工具帮忙（例如让它帮你找段落或改措辞），可以用，但要做到两点：在交回的 `freeze.json` 里写明用了什么工具、用在哪一步；每条参考答案都由你本人对照原文确认过。不要把这份说明以外的项目材料给 AI 工具看。

## 二、你会拿到什么

一个文件夹，里面有：

| 内容 | 说明 |
| --- | --- |
| `资料清单.txt` | 七份资料的编号（资料1—资料7）、文件名和散列值 |
| 七份资料原文 | 河南省居民身份证相关的历史归档文件：规范条文、通知与网页正文、Excel 收费目录、扫描件（附两页图片和文字转录） |
| 本说明 | 就是这份 |
| `出题表模板.csv` | 用表格填写时用（见第六节） |

这七份是**历史归档**，不代表现在的政策。出题时把它们当作“一个档案柜里的全部文件”：题目只能问柜子里的内容。

请先花 1 小时把七份资料都通读一遍，再开始出题。

## 三、出多少、出哪几类

共 **24 道**，编号 X01—X24，四类数量固定：

| 类别（`category`） | 含义 | 数量 |
| --- | --- | --- |
| `comparison` 比较 | 要把**两份**资料里的规定并排说清才能回答 | 8 |
| `temporal` 时间 | 同一事项在不同文件里先后有不同规定，或问某份文件的发布、施行日期 | 4 |
| `inference` 推理 | 要把两处原文合起来才能得出答案，任何一处单独都不够（可以是同一份资料的两处） | 4 |
| `should_stop` 应停止 | 依据这七份资料**不应当作答** | 8 |

另外：

- 应答复的 16 道里，**至少 3 道**的答案在 Excel 收费目录的某一行里；
- 应答复的题，除 `inference` 外，答案都要用到**至少两份不同的资料**；
- 七份资料每一份至少出现在 2 道题的来源里，扫描件至少 1 道；
- 题号顺序随意排，**不要**把同一类题排在一起。

## 四、题面怎么写

- 像一位普通群众或窗口工作人员会问的话，自然、具体；
- 不超过 80 个字；一道题只问一件事，或者并列的两件事（例如“A 和 B 分别是多少”）；
- 不在题面里写出答案、来源编号或“请比较资料几和资料几”；
- 不加任何固定前缀或格式说明。

## 五、应停止的题怎么出（最需要用心的部分）

8 道分四种原因，**每种 2 道**，在参考里用 `stop_reason` 标明：

| `stop_reason` | 什么情况 | 怎么出才好 |
| --- | --- | --- |
| `insufficient` 证据不足 | 资料里有相关内容，但缺回答必需的关键一项 | 让人第一眼觉得能答，读了资料才发现缺那一项 |
| `conflict` 版本或来源冲突 | 两份资料对同一事项说法不同，而且**资料本身没说清**以哪份为准 | 如果后一份文件明确写了“废止”“代替”前一份，那是可以回答的时间题，不算冲突 |
| `branch` 分支不符 | 资料只规定了另一种情形（例如只有换领的规定，题目问的是补领） | 问法要像是在问资料里那件事 |
| `out_of_scope` 超出范围 | 问现在是否仍然有效、问河南以外地区的办理，或题面带个人证件信息 | 两道分别选不同的情形 |

规则：

- **前三种（6 道）的题面里不要出现**“现在、目前、今天、今年、最新、现行、还有效”这类字眼，**也不要出现外省地名或证件号码**。它们要靠读证据才能判断不该答。
- 只有 `out_of_scope` 的 2 道可以用这些字眼。题面带个人信息时，请编造明显虚构的内容，不要用任何真人的信息。
- 判断口径：资料是历史归档，凡是要求判断**现在**是否有效、**现在**该怎么办的，一律算应停止。问“按这份归档文件当时的规定……”是可以回答的。

`stop_basis` 写清两件事：属于哪种原因；资料里缺的是什么，或冲突在哪两处（写来源位置）。

## 六、交回什么

三个文件，二选一的方式：

**方式一（会写 JSON 的）：** 直接写 `questions.json`、`reference.json`、`freeze.json`。

**方式二（用表格）：** 用 Excel 或 WPS 打开 `出题表模板.csv` 填写，**另存为 CSV（UTF-8）**，再单独写一个 `freeze.json`（照下面的样子改即可，也可以写成 txt 交给陈转换）。陈用程序把表格转成两个 JSON 文件后，会把转好的文件给你看一遍，你确认无误后才算交回。表格里一格要写多条时，用竖线 `｜` 分隔。

### questions.json：只有题号和题面

```json
[
  {"id": "X01", "question": "……"},
  {"id": "X02", "question": "……"}
]
```

### reference.json：每题一条

下面用一个**虚构的图书馆借阅题**演示格式，与本次资料无关：

```json
[
  {"id": "X01", "expected_outcome": "answer", "category": "comparison",
   "key_points": ["普通读者每次最多借5册", "教师读者每次最多借10册"],
   "sources": ["资料2 · 第六条", "资料4 · 表格第3行"],
   "quotes": ["普通读者每次限借图书5册", "教师读者限借10册"],
   "must_not": ["把“册”写成“本次累计”"]},
  {"id": "X02", "expected_outcome": "stop", "category": "should_stop",
   "stop_reason": "branch", "key_points": [], "sources": ["资料2 · 第八条"],
   "stop_basis": "分支不符：资料只规定了图书逾期的处理，题目问的是光盘逾期"}
]
```

各字段：

| 字段 | 要求 |
| --- | --- |
| `expected_outcome` | `answer`（应答复）或 `stop`（应停止）；`should_stop` 类一律 `stop` |
| `key_points` | 应答复题必填，每题 2—4 条。每条是一个能单独核对的事实，写清**对象、数值、单位**和适用的情形 |
| `sources` | 每条要点的来源，写成“资料编号 · 位置”（条款、段落、表格第几行或列名），让别人能翻到 |
| `quotes` | 每条要点对应一段**逐字照抄**的原文（不超过 60 字），条数不少于 `key_points`。不要改字、不要补标点 |
| `must_not` | 选填：哪些说法算错（例如把工作日写成自然日、把首次申领的规定套到补领上） |
| `stop_reason`、`stop_basis` | 应停止题必填，见第五节 |

### freeze.json：你的出题记录

```json
{
  "author_role": "例如：外系同学，未参与本项目",
  "files_read": ["本说明", "资料1", "资料2", "资料3", "资料4", "资料5", "资料6", "资料7"],
  "ai_tools_used": [],
  "started_at": "2026-11-21 14:00",
  "finished_at": "2026-11-21 20:00",
  "declaration": "我出题时没有看过该问答程序的代码、文档、以前的题目或任何回答，题目和参考答案由我本人对照原文完成。"
}
```

不写你的姓名、电话、学号。用了 AI 工具就在 `ai_tools_used` 里写，例如 `["某某助手：帮忙查找段落，所有要点本人核对"]`。

## 七、写完后自查

- [ ] 24 道，X01—X24 连续，两个文件的题号完全一致；
- [ ] 四类数量是 8 / 4 / 4 / 8，应停止题四种原因各 2 道；
- [ ] 每道应答复题有 2—4 条要点，每条要点有来源和逐字原文；
- [ ] 除推理题外，应答复题至少用到两份资料；至少 3 道用到 Excel 收费目录；
- [ ] 前三种应停止题的题面没有“现在、目前、最新、现行、还有效”和外省地名；
- [ ] 每道题都不超过 80 字；
- [ ] 写了 `freeze.json`。

## 八、交回与之后

- 只交给**陈**一个人，私下传（例如当面拷贝或私聊发送）。**不要**发给李、程，也不要上传到任何网站、网盘公开链接或群里。
- 陈收到后会立刻记下三个文件的散列值。**从这一刻起文件就冻结了**：之后发现哪里写错，不要改原文件，把更正写在一个单独的说明里交给陈，原文件保持不变。
- 陈会用程序做格式检查，并请一位不参与评分的人复核“题意有没有和旧题重复、参考答案和原文是否一致”。他们发现的问题会另行记录，不会替你改题。
- 评测全部结束前，请不要和任何人讨论题目内容。

有格式上的问题随时问陈；内容上怎么出题，请按自己的判断来，不需要问任何人。
