## 同学复现步骤

前提：已安装Git及Python 3.11或以上，`python --version`能显示正确版本。首次需要访问PyPI下载依赖；不需要Docker、Ollama、模型下载或本机历史数据库。本轮支持状态以实际Windows验收记录为准。

在PowerShell中执行，克隆目录请选一个尚不存在的目录：

```powershell
git clone --branch feat/m2-minimal-flow --single-branch https://github.com/miller7-lan/huaweiICT.git huaweiICT-demo
cd huaweiICT-demo
python scripts/team_demo.py init
python scripts/team_demo.py serve
```

浏览器打开 `http://127.0.0.1:18772`，选择群众端或工作人员端，点击“查询原文证据”。保留启动终端；按 **Ctrl+C** 停止这次演示。不会开启五分钟心跳。

另开PowerShell，在同一个克隆目录执行：

```powershell
python scripts/team_demo.py check
python scripts/team_demo.py update
python scripts/team_demo.py query --role staff
python scripts/team_demo.py check
```

`init`建立v1。`update`只允许执行一次：重放v2虚构HTML，先实测待核停止，再由明确的模拟执行身份复核并发布到独立演示库。两次检查均应输出 `passed: true`。页面刷新后，默认查询v2的“模拟材料乙”，选择v1可看到“模拟材料甲”。这不是人工业务审批，也没有改动真实业务发布策略。

演示数据默认在 `.runtime/team-demo`，依赖环境在 `.runtime/team-demo-env`，两者均不进Git。`demo-check.json`保存最近一次检查明细；原件在演示数据目录的 `originals/` 中。`check`不重新下载或静默刷新来源观察；隔天提示来源需要重查时，可显式运行 `python scripts/team_demo.py refresh` 重放当前本地虚构HTML，版本保持，不声称网络复查成功。

## 常见问题

- `python`不存在或版本低于3.11：先安装可用的Python并确认PATH；不必改动原项目的虚拟环境。
- 首次依赖下载失败：查看 `.runtime/team-demo-env/install.log`，修复PyPI网络后，使用新的环境目录，例如 `python scripts/team_demo.py init --environment .runtime/team-demo-env-retry`；后续命令也传同一参数。不会关闭TLS验证。
- 初始化提示目录非空：已有演示用 `check`；重新演示时指定新的 `--runtime .runtime/team-demo-2`，不要把旧业务库当作演示目录。后续命令使用相同目录。
- 18772被占用：先确认占用者；可用 `python scripts/team_demo.py serve --port 18774`，不结束其他项目进程。
- 已更新过v2：继续运行 `check`，或选新空目录重新初始化；不自动清空已有原件。
- 网页查询失败：查看启动终端和 `demo-check.json`；任何真实办事问题均不得据虚构示例得出结论。
