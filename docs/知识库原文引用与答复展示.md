# 知识库原文引用与答复展示

2026-10-16完成的阶段更新。代码入口为[原文绑定与展示](../src/gov_mcp/knowledge_answers.py)、[已发布查询](../src/gov_mcp/knowledge.py)和[身份鉴权工具](../src/gov_mcp/knowledge_tools.py)。本阶段沿用已发布资料查询与现有Nexent固定代码动作，不启动另一轮30题自由生成，也不修改原/M1/M2或咨询预览Agent定义。

## 返回内容

`search_evidence`在原有`status/items/citations/knowledge_version/message_code/data`上追加字段；现有字段继续返回。已鉴权角色的咨询结果新增`data.answer`，由程序直接组织完整命中原文及来源说明。群众端显示“办事咨询依据”，工作人员端显示“工作人员核对依据”。它是可核对的依据展示，尚未实现材料组合的业务推理，也不构成审批决定。

每条引文包含：

| 字段 | 含义 |
| --- | --- |
| `citation_id` | 根据版本、修订、父片段序号、原文、定位、来源及日期等内容生成的稳定完整哈希标识 |
| `original_sha256` | 留存原件的SHA-256；沿用数据库的原件、正文与复核摘要校验 |
| `chunk_ordinal` / `text_sha256` | 修订内父片段序号、未改写原文的UTF-8哈希 |
| `source_span` | 完整父片段区间`[0, len(quote))`，以Python Unicode字符计数；基准明确为抽取父片段，**不是PDF文件或页面的字节坐标** |
| `published_at` / `effective_from` / `effective_to` | 独立的发布日期、生效日与失效日；未确认的发布日期直接显示“未确认”，不从URL年份推断 |

原文保留空格、换行、OCR字形、标点和完整条件，不截成固定字数，不由模型重新抄写。内部选择函数只接收目录中准确的引用标识；未知/重复标识、替换引句或区间、混用版本均拒绝。当前工具默认展示原排序命中的全部引文，没有开放访客传入引用目录或任意区间的接口。哈希用于完整性核对，不是数字签名，也不能证明政策现行效力或语义相关性。

## 日期和停止行为

`data.query_date/query_view`区分当前、历史日期与未来日期筛选；`historical_snapshot`仍单独表示选取了旧知识库版本。历史日期筛选不冒充重建了当时的网站状态，未来日期筛选不保证文件未来仍然有效。日期和版本判断沿用现有已发布查询规则，本阶段未更换正式排序、扩大适用范围或放宽发布闸门。

待复核、待发布、来源检查失败、没有已发布版本、问题超范围、个人信息或资料读取失败时，结果仍为空证据并显示明确停止说明。未配置身份仍返回空`data`。工具不回显被拒绝的个人信息。Nexent现有动作原样返回最后一次真实工具结果，因此新增展示信息沿现有链路输出。
