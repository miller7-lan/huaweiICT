# 知识库文件发现适配说明

2026-10-16。发现功能支持显式配置的HTML索引、RSS、Atom和普通XML sitemap。真实源目前仅启用原北京政策HTML栏目；订阅及sitemap的测试使用隔离模拟数据，没有凭空启用官方订阅地址。

## 扫描与延期

- 来源必须先有访问/使用筛查、域名和路径范围，每个真实请求仍检查robots、公开IP、跳转及限速。分页和订阅不能扩展权限范围。
- 每轮默认最多10个索引页、深度10、25个新文件任务；配置上限分别为25、20、100。每页最多保存2000条匹配链接。达到上限留下明确状态，不称为全站覆盖。
- HTML按指定id/class扫描文档区；只有明确next链接或分页区域的下一页链接作为后续索引，不把导航和页脚文档混入。链接去片段后去重，中文路径在HTTP请求中编码。
- RSS/Atom保存条目标识和报告日期，sitemap保存lastmod。日期只用于优先检查与变更线索，不填入法律发布日期或生效日。
- 索引角色、每轮访问集合和链接缓存持久化。相同来源不重叠启动轮次，分页循环不重复排队，未访问的子索引优先于已检查页进入后续轮次。
- 304会重放上次链接缓存，达到新文件上限的延期链接可在后续轮次继续排队；解析截断也保留提醒。曾发现文件持续复查，链接消失不自动推断文件被废止。
- 订阅条目标题/日期变化时，正文即使返回304，也用已校验归档产生新的待复核修订，清空旧业务日期，不把“正文未变”当作元数据未变。没有归档原件的文档304不能记为检查成功。
- 只接受匹配配置格式的MIME和结构。XML限5MiB、UTF-8、32层及3万节点，拒绝DTD和实体声明；gzip sitemap、通用API、其他编码和OCR尚未实现。

协议依据：[RSS 2.0规范](https://www.rssboard.org/rss-specification)、[Atom RFC 4287](https://www.rfc-editor.org/info/rfc4287/)、[Sitemap协议](https://www.sitemaps.org/protocol.html)。这些适配器实现了本任务需要的有界子集，不宣称支持协议所有扩展。

## 适用范围与发布保护

发现资料默认地区未知、事项未分类，不能继承入口所在城市。`watch_scopes`登记它可能影响的试点范围：出现尚未分类的候选时，该范围停止现行依据回答；核定范围或有理由排除后再恢复相应流程。未知范围不能直接复核通过。

监测源配置参与评测绑定，暂停、停用或超期也参与当前来源新鲜度检查。增加监测入口后旧评测报告不能复用。工作台新增“文件发现覆盖”，显示本轮索引任务、新文件任务、未访问缓存目标、失败及上限提醒。

## 本机实际记录

[升级证据](../evidence/knowledge-update/discovery-upgrade.json)记录原访问核查信息、其他来源和暂停状态在配置迁移时均保留。对2026-10-15缓存HTML的离线检查发现指定列表有999条政策链接，身份证关键词匹配0条；网页脚本对返回列表做客户端分页，故解析全部已返回列表，不猜造页码URL。这是历史缓存解析证据，不能证明当前网站的全量库存。

本次升级另经正常采集器执行了一次真实栏目检查：1个索引页完成，相关新文件0个、延期目标0个，没有新增业务文件。实际RSS/Atom/sitemap来源仍待逐一取得官方入口及访问依据后接入。
