# 知识库变更影响与同文核查

2026-10-16。新增只读变更分析，用于定位需要继续核查的差异；不自动决定材料关系、适用范围、政策效力或文件合并。

## 对照一份修订

默认选同一文件之前最近的修订，先校验双方原件及片段指纹，再对照定位、正文、分类和元数据字段。可指定更早基线，但不能选其他文件或较新的修订。

```powershell
.\.venv\Scripts\python.exe -m gov_mcp.knowledge_cli --runtime .runtime/knowledge-update impact <修订ID>
.\.venv\Scripts\python.exe -m gov_mcp.knowledge_cli --runtime .runtime/knowledge-update impact <修订ID> --base <更早修订ID> --include-excerpts
```

结果区分首次候选、正文/定位变化、分类变化、字段变化、空白格式变化及仅原始表示变化。内部重现顺序标记不当作政策字段。报告有分析版本与指纹；完整前后文本仅在显式要求时导出，最多100个定位，截断会标明。

工作台待复核资料下有“查看与前一修订的差异”，按需调用本机只读接口，不加载整个库。默认页面只显示变化摘要，不提供复核或发布按钮。

## 跨来源同文候选

```powershell
.\.venv\Scripts\python.exe -m gov_mcp.knowledge_cli --runtime .runtime/knowledge-update duplicate-candidates
```

仅比较每份文件的最新修订，检查相同原件字节、去空白后相同的选入正文（至少80字符）、相同的长条款文本（至少80字符）以及相同的所报文号。部分同文会单列双方定位，不能由一个相同条款推断全文相同。每组保留来源、URL、修订和原件指纹。相同文号可能对应不同版本；去空白文本相同也不证明元数据、地区或效力相同，所以不合并、不删除、不自动通过。

[实际候选分析](../evidence/knowledge-update/revision-impacts.json)覆盖21份当前归档：5份首次候选、16份元数据差异（含目录信号、附件观察与AI排除决定）；检测到2组法律长条款部分同文。新增法律转载选入12条，与旧4条选段的第11、12条一致，仍保留各自原件和日期冲突；河南期限说明选入1段事实，省厅规范HTML选入14条。页面观察字段补录是数据库记录的变化，不能称为官方最近修改政策；新增转载不计作新法律。

## 复核包与现有边界

`scripts/export_knowledge_review_packet.py`现将逐份变更的完整前后片段、分类建议、同文候选和30题AI参考答案一并放入私有复核包。AI作者与真人签署空白字段分开记录，保持真实身份。运行`scripts/record_knowledge_impacts.py`可重新生成可共享摘要。

当前仍有来源访问及现行适用缺口。对原先超时的省级来源做过一次正常robots复查，仍超时，因此没有请求PDF或恢复采集，见[复查记录](../evidence/knowledge-update/provincial-access-recheck.json)。其他已拒绝来源没有因此重试或换身份访问。
