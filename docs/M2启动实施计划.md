## 要完成的结果

在三人核定一个地区、一个事项与使用范围之后，建立独立的 M2 环境，实现群众有依据的引导→保存交接→工作人员材料前提核验。每条业务说法能追溯原文，同一任务及交接固定知识版本，关键处理意见由工作人员确认。

本轮交付的是启动规划、官方事项候选核查与接续记录。规划文件不是业务规则、正式赛事要求或已完成的 M2 验收。

## 字段契约草案

下表为逻辑对象，字段尚未进入数据库。正式定稿时补充类型、枚举、长度、约束和迁移版本；未经来源确认的业务字段不得用默认值伪装成事实。

| 对象 | 核心字段 | 必须保持的约束 |
| --- | --- | --- |
| 事项 matter | 内部 `matter_id`、官方 `matter_code`、地区、部门、scope、review_status | 内部 ID 与官方编码分开；官方编码未知可为 null，但不能造编码；首版只允许核定的范围 |
| 来源 source | `source_id`、title、issuer、url、retrieved_at、published_at、valid_from/to、sha256、usage_scope、review_status、reviewer | 发布时必须有真实原件指纹、来源与复核记录；日期未知为 null 并说明；抓取时间不能当生效时间 |
| 引文 citation | `citation_id`、source_id、version_id、locator、原文片段 | 指向固定源文件/网页快照及段落；与结果所用版本一致；模型不能生成不存在的 citation_id |
| 材料规则 requirement | `requirement_id`、matter_id、version_id、条件、requiredness、alternative_group、citation_ids、review_status | 必交、条件交、择一、共享获取区别建模；条件未知转人工，不能强制要求所有分支材料 |
| 版本 version | `version_id`、matter_id、快照清单及指纹、state、created_at、review_record | 发布后不可覆盖；首版只发布一个经复核快照，后续真实变化属于 M3 |
| 任务 task | `task_id`、服务端 tenant/owner、matter_id、version_id、范围声明、state、created_at | 创建时服务端绑定当前已发布快照；后续工具不能自行换版本；未知范围停止 |
| 材料声明 material | `material_id`、task_id、requirement_id、presence、verification_state、input_origin | 首版只记录模拟输入的存在/缺失/未知及人工核验状态；声明存在不等于文件真实有效 |
| 交接 handoff | `handoff_id`、task_id、version_id、summary、citation_ids、未确认项、state、idempotency_key、created_by | 保存服务端事实及原引用；重复键复用原交接，同键不同内容报冲突；不得通过自由文本增补事实 |
| 核验 assessment | `assessment_id`、handoff_id、version_id、missing/unknown、人工意见、reviewer、confirmed_at | 只判材料前提与引用支持性；正式处理意见必须人工；确认绑定版本和结果指纹 |
| 审计 audit | `request_id`、实际 tenant/主体摘要、role、tool/action、task/handoff、version_id、status、message_code、duration | 真实生成并关联 API、工具/SSE、页面；不伪造模型请求计数或会话 ID；公开记录不含凭据/申请人信息 |

版本引用和字段外键在服务端校验。字符串匹配或模型认为“差不多”不能作为材料真实有效性判定。首版不保存身份证照片、身份证号码或真实申请人姓名。

## 工具与页面契约

继续使用 `status/items/citations/knowledge_version/message_code/data`。`data` 至少携带实际 request_id、服务端确定的 role、相关 task_id/handoff_id。新增 message_code 均为提议，实施时由契约测试固定。

| 拟议工具 | 业务输入 | 权限与真实行为 |
| --- | --- | --- |
| `govm2_get_environment_status` | 无业务输入 | 登录主体由受信入口核实；返回配置、角色、可见事项及发布状态 |
| `govm2_search_evidence` | task_id、query | 只搜该任务固定版本和可见范围；返回可定位引文；无依据时 EMPTY/NO_SUPPORTING_EVIDENCE 并停止该说法 |
| `govm2_query_knowledge_graph` | task_id、object_id 可选 | 可仅实现来源→事项→材料的经复核关系；不宣称已覆盖原策划书全部七类对象 |
| `govm2_create_handoff` | task_id、需核对的材料声明引用、idempotency_key | 新增第七个业务工具；校验任务所有权，持久化交接和同版本引用，返回实际 handoff_id |
| `govm2_check_case_prerequisites` | handoff_id | 仅授权工作人员；校验租户/受理范围，返回 missing、unknown 与证据；齐备只表示可进入人工复核 |
| `govm2_prepare_update` | 受控来源清单引用 | 仅知识维护权限；M2 限首版来源导入候选，失败不生成已发布版本 |
| `govm2_publish_update` | candidate_id、人工复核记录引用、确认标记 | 仅知识维护权限；核对来源审查、候选指纹与人工确认后发布首版快照，记录审计 |

业务工具不允许模型或网页提交角色来获得权限；tenant/user 如为传输字段，应由经过会话核验的受信入口注入并与服务端映射校验。服务令牌留在私有配置。越权检查先于来源内容、材料与任务数据返回，跨租户或越权对象不得泄漏。

群众页面顺序：确认范围→有依据的材料引导→显式标记未知→请求交接→显示版本、引用和实际交接号。工作人员页面顺序：读取有权处理的交接→核对材料缺项→显示原文依据→记录人工确认。陈子炫设计页面时先让这些状态可见，再接 Agent。

## 状态与停止条件

| 情况 | 建议结果 | 页面与后续操作 |
| --- | --- | --- |
| 未确定事项/未发布快照 | BLOCKED/MATTER_NOT_CONFIRMED 或 KNOWLEDGE_NOT_PUBLISHED | 显示前提缺失，停止引导与交接 |
| 来源待复核或差异未解 | BLOCKED/SOURCE_REVIEW_REQUIRED | 展示需人工复核的来源，不能给确定办理答案 |
| 检索无支持依据 | EMPTY/NO_SUPPORTING_EVIDENCE | 引用为空，停止相关业务推理 |
| 材料缺项或声明未知 | BLOCKED/MATERIALS_INCOMPLETE 或 MATERIALS_UNVERIFIED | 分别显示 missing 和 unknown，不输出审批结论 |
| 材料前提齐备 | OK/READY_FOR_HUMAN_REVIEW | 可进入人工复核，不自动结案或审批 |
| 版本、对象、幂等冲突 | BLOCKED/KNOWLEDGE_VERSION_MISMATCH、OBJECT_NOT_FOUND 或 IDEMPOTENCY_CONFLICT | 不自动换版本、不创建第二个交接 |
| 越权、身份未配置 | BLOCKED/FORBIDDEN 或 ROLE_NOT_CONFIGURED | 无业务数据返回，不执行后续工具 |
| 缺连接、超时、存储错误 | ERROR/CONNECTION_NOT_CONFIGURED、TOOL_TIMEOUT 或 STORAGE_UNAVAILABLE | 有限重试并停止；技术故障不能改写成材料不合格 |

任务状态建议为 `draft → guided → handed_off → awaiting_human_review → reviewed`，允许在阶段内停留并补充材料。`reviewed` 只代表人工核验记录，首版没有“已审批”状态。新版本发布只影响新任务，历史任务及其交接继续读原快照；变更任务版本须显式新建任务，不能静默重绑定。

| M2-12 | 连续演示及指标 | 两端实际操作、引用、交接、人工环节和失败状态可见；报告分母与局限 |

建议首轮不少于 30 个经人工复核的留出任务，属于原计划的内部建议而非已确认赛题评分线。按独立案例/场景组划分，同一案例及其改写不能跨开发与验收；固定官方知识语料可以共享，留出问题和答案不能用于调提示词。来源不足时不编造 30 个“真实案例”，应报告任务数量、覆盖缺口和条件依赖。

引用支持性记录支持数/已核查说法数；缺项识别记录正确检出数/人工判定缺项数，同时报告误报；权限、版本和故障场景逐条通过。95% 是既有计划提出的内部目标，仍需团队核定；样本不足或分母为零时不宣称达标。M3 的真实变化识别指标不属于本轮 M2 完成声明。
