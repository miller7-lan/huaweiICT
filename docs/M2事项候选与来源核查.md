# M2 事项候选与来源核查

核查时间：2026-10-13（北京时间）。用途：团队选择事项和人工复核的准备材料。状态：候选，未导入业务库，未成为正式办理规则。

## 建议选择

建议地区为河南省郑州市二七区，建议事项为“居民身份证到期换领”。首版只考虑成年人、本地户籍、本人到期换领；未成年人、异地办理、丢失补领、代理办理和其他换领原因不在建议首版范围。

这是为了缩小工程演示范围提出的建议，不代表用户所在地区，也未代替三人的事项确认。页面把到期与其他换领原因放在同一标题下，实施时必须拆分范围，不能把所有分支的材料合成一张必交清单。

## 已实际读取的官方来源

下面只登记出处、位置及核查结果。没有下载并归档原始文件，因此文件 SHA-256、原始网页快照、许可确认和人工签名均为待采集；不填写猜测值。所有来源状态为 `pending_review`。可访问不等于已完成版本有效性或再分发授权审查。

### S-A1：二七区身份证换领指南

- 官方标题：居民身份证到期换领、其他原因换领。
- 页面：[二七区基层政务公开](https://eq.jiceng.zhengzhou.gov.cn/004008002/3394639.jhtml)。页面列示单位：郑州市公安局二七分局户籍室。
- 核查位置：标题下条件信息、办理流程、四项材料列表。网页无 PDF 页码；后续归档时建立稳定的段落编号。
- 核查结果：页面分别列出户口簿、原身份证、未成年人监护材料和异地办理说明。本地成年人到期换领可作为候选范围，但材料替代、采集要求与当前执行口径仍须人工确认。未在读取结果中取得发布日期、事项编码或有效期；均保留未知。

### S-A2：金水区身份证换领指南，作为比较资料

- 页面：[金水区基层政务公开](https://js.jiceng.zhengzhou.gov.cn/004008002/3541111.jhtml)。页面列示单位：郑州市公安局金水分局。
- 核查位置：材料列表与异地办理说明。
- 用途：验证同一市内其他区也存在按年龄及异地条件区分的说明。它属于其他地区，不能直接替代二七区规则，也不能作为二七区缺项的补全来源。发布时间在读取结果中未取得。

### S-B1：二七区居住证首次申领指南

- 页面：[二七区基层政务公开](https://eq.jiceng.zhengzhou.gov.cn/004006002/3389298.jhtml)。页面列示单位：郑州市公安局二七分局户籍室。
- 核查位置：申领条件、办理流程及材料列表。
- 核查结果：页面涉及暂住登记时长以及就业、住所、就读的条件分支。材料依申请情况选择，不能把每一类证明同时设为必交。发布时间和当前适用状态在读取结果中未取得。

### S-B2：郑州市居住证政策解读

- 页面：[郑州市公安局政策解读](https://public.zhengzhou.gov.cn/D3602Y/4896908.jhtml)。页面显示发布日期 2021-02-18。
- 核查位置：目标任务、主要内容中的申领条件、证明材料和信息共享。
- 核查结果：市级解读提到部分条件不受公安登记满半年限制，也说明材料共享机制。与 S-B1 的简化表述存在需要核对的差异；尚不能直接裁定哪段适用于首版具体申请范围。

### S-B3：郑政办〔2021〕8号的官方发布页

- 页面：[关于进一步明确我市居住证办理有关事项的通知](https://public.zhengzhou.gov.cn/D0107Y/10036572.jhtml)。来自 S-B2 的关联政策链接。
- 实际读取：元数据页显示文号、2021-02-18 日期及“有效”标记，并提供政策 PDF。
- 阅读边界：本轮没有打开或解析该 PDF 正文；不能将元数据页的摘要或状态标记写成已经核对过正文、后续修订或废止情况。
- 下一动作：程千城读取正文和附件，登记原始文件指纹、适用范围与后续修订；对 S-B1/S-B2 差异形成复核记录。

## 给后端的约束

未经人工复核的资料可以出现在“待复核来源”清单，但不能发布为可用于办事引导的知识快照。不同地区的材料不得拼接；来源冲突应返回待复核状态，不由模型选一个看起来合理的答案。

本轮没有申请人记录、材料附件或业务标准答案。后续开发输入如采用人工设计的材料存在/缺失组合，必须标明模拟输入、编写人和依据；不得称为真实办理案例。金额、时限、窗口地址等容易变化的信息不作为首版演示核心输出，确需输出时逐条引用并人工复核。
