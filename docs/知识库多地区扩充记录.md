# 知识库多地区扩充记录

2026-10-18用户明确调整优先级：扩大数据库，可以更换地区和事项；单个事项推不动时继续其他方向。因此，二七区未决项保留为局部待核问题，不再作为整个资料库扩充的阻塞条件。[扩充策略](../config/knowledge-expansion.json)独立于原试点问答范围；原`knowledge-scope.json`仍用于二七试点，不能误作全库采集上限。

每批按官方原文可得性、地区和事项范围独立推进。正常采集取得原件、选择完整相关段落、记录出处/日期/定位/哈希、实际入库和校验后即完成一批扩充并推送GitHub。当前效力或条件尚未核定的资料标为待核，历史材料明确标为历史对照；逐项业务发布另行按相应地区和事项核定，不以单一区域全部验收作为扩库门槛。
