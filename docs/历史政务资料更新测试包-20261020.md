# 历史政务资料更新测试包（2026-10-20）

用户要求整理旧政务资料供AI检查更新测试，并补充网上约10年前、5年前的官方文件，上传GitHub供队员使用。

完整包：[ZIP](../data/knowledge/historical-update-benchmark-20261020.zip)；[解压目录与使用说明](../data/knowledge/historical-update-benchmark-20261020/README.md)。

被测AI专用：[只含旧资料的ZIP](../data/knowledge/historical-old-inputs-only-20261020.zip)，不包含评测员目录及2026河南后继资料。

本包有7份独立SQLite知识库及TXT、JSON、原始HTML，共165段：2016年户口登记、2016年城乡居民医保整合、2019年杭州居住证、2021年天津居住证、2021年职工医保门诊共济、2023年北京租房公积金、2024年河南身份证时限。2016/2021资料对应约10年前/5年前。

本次网上新增3份，均从中国政府网或国家医保局官方公开页面收集；其余4份对应GitHub既有资料记录，原件与选段哈希已核对。本次生成的SQLite属于便携测试输入，不是历史年份已经上传的数据库，也不可替换项目运行数据库。

仅向被测AI提供 `input_old_only/`；`evaluator_only_do_not_import/` 留给评测员，避免预期答案泄漏。只有河南提供明确的新旧后继样本，其他样本尚无独立现行标准答案，用于开放查新和日期、范围、证据边界核查。不能把找到新文章或文件年代较久直接判作旧文件废止。

运行包内 `python verify.py` 检查文件清单、哈希、SQLite完整性及段落与原文对应。实际被测模型运行0次，真实更新链路及业务效果未执行；不启用任何自动更新任务。
