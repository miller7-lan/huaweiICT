# 知识库申请与领取范围核查

日期：2026-10-16。试点仍为郑州市二七区、成年本地户籍、本人居民身份证到期换领。本次修正查询范围判断，不核定任何人的代领资格，也不批准候选政策。

## 修正后的接口行为

原范围规则把“代领”直接归入“代理申请”，因此“本人已申请到期换领，能委托家属代领新证吗？”被范围拦截。现在按问题表达的办理环节处理：

| 问题表达 | 行为 | 当前真实库结果 |
| --- | --- | --- |
| 本人申请后的新证领取 | 进入原有已发布知识查询 | `NO_PUBLISHED_KNOWLEDGE`，因为正式版本仍为0 |
| 明确由他人申请、申领或办理身份证 | 维持范围拦截；混合问法中明确代理申请优先 | `OUT_OF_CONFIRMED_SCOPE` |
| 只说“代办”“委托家属”，未说环节；领取凭证和成品新证混淆等 | 查询前要求澄清 | `SCOPE_CLARIFICATION_REQUIRED` |

澄清提示为：“请说明他人参与的是申请办理、材料协助，还是本人办理申请后的新证领取环节；无需提供身份证号码。”查询使用访问者原问题，内部去空白处理只用于范围判断。未成年、异地户籍、丢失损坏、临时证、身份信息变更等既有试点限制继续优先检查；角色由可信身份映射确定，个人信息检查仍先于范围判断，维护操作仍不开放。

允许进入查询只表示问题可以检索已发布证据。国家材料的“亲属”和省级材料的“他人”措辞及当前本地适用关系仍待核查，不能由范围规则推导出“任何人都可代领”。[后续政策核查](身份证换领后续政策适用核查.md)和[原文措辞核对](../evidence/knowledge-update/proxy-collection-wording-check.json)保留具体来源。

规则使用有界字词与短语匹配：问题上限300字符，委托与动作间最多跨16字符，遇到其他动作、信息协助表达及标点停止。支持少量明确否定表达；并非完整的自然语言理解，复杂指代、否定和多主体问法仍有识别局限。范围停止或澄清是本试点的处理结果，不是行政办理资格结论。
