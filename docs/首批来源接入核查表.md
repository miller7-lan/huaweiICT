## 两个河南来源的复现入口

已存在的来源用日常监测或`--validate-only`检查原件，不重复运行首次接入。新运行目录初始化及依赖准备完成后，可使用以下入口重新执行正常访问检查；它们只保存私有原件、待核查元数据和选段，不发布业务知识。

```powershell
# 每条首次接入只运行一次；既有来源会拒绝覆盖
.\.venv\Scripts\python.exe scripts\intake_henan_sources.py --source service-update
.\.venv\Scripts\python.exe scripts\finalize_henan_update.py
.\.venv\Scripts\python.exe scripts\intake_henan_sources.py --source norm-publisher
.\.venv\Scripts\python.exe scripts\finalize_henan_norm.py
# 最新解析程序部署后，才启用定时监测
.\.venv\Scripts\python.exe scripts\finalize_henan_update.py --enable-monitoring
.\.venv\Scripts\python.exe scripts\finalize_henan_norm.py --enable-monitoring
# 本机已有原件的无网络核验
.\.venv\Scripts\python.exe scripts\intake_henan_sources.py --source norm-publisher --validate-only
```

原件缺失、内容选择变化、访问拒绝或TLS异常时保留停止结果，不通过关闭检查、换身份或复写旧证据继续。公开目录只有定位与指纹，不能直接替代私有原件备份。
