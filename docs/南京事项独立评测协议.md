# 南京事项独立评测协议

状态：等待独立评测人及未参与开发的真实问题，尚未执行、没有准确率。用户要求暂保留候选，评测不会开启正式业务发布。已通过异步问题请求评测负责人和问题；在收到前完成协议与提交模板准备。

由未参与当前实现/提示词修改的队友或老师负责出题及参考结论，记录真实身份或获认可的评测代号、独立性声明、时间和官方原文定位。不得虚构评测人、人工投入或已批准结论，不收集申请人姓名、身份证号等真实隐私。

`evaluation/real-matter-closure/independent-submission.template.json` 为待填写模板，空案例组不是已冻结测试集。每组对应一个真实问题原型及所有改写，先整组冻结问题、声明条件、允许答案/恰当停止、引用原文与定位；同义改写、同源同结论和四条替代证明不能跨训练/留出分割或重复计数。南京旧证生命周期及当前材料/时限等已用开发问题必须披露，不得在留出中冒充首次独立样例。

评测前封存提交文件哈希、来源包/本体版本、实现提交和模型配置。参考文件先冻结，再做任何预测；运行后不修改参考以迁就结果，争议另开人工裁决并保留原标签。评测人先确定例数，不用模型输出反向挑选易题。以当前小范围南京成年本人、完全民事行为能力、江苏户籍期满换领为主分支；省外/未成年人/不明能力、遗失损坏、过期历史、撤权冲突作为恰当停止组。范围外问题的停止应以实际定义判断，不能事后删除。

对照至少固定同一输入来源的种子本体、仅加来源、演化关系三个程序版本，区分确定性推导与真实Qwen编排。模型运行另列真实工具轨迹、子Agent、预算失败/超时、结构化输出及版本绑定；未运行模型的题不能计模型成功。额外真实运行应先确定完整明确预算，再执行，不因失败自动加次数。

逐组报告：回答正确/部分/错误、引用覆盖与定位、适用条件、正确停止/误拒答/越界回答、多文档依赖成立、版本/当前暂停检查、人工复核用时（实测才填）。分别给出分子/分母，缺失/未跑单列；样本少时报告区间与限制，不以测试断言数代业务准确率，不以证据路径数代独立案例数。

对外交付须同时提供冻结输入、参考依据（如需盲评则评测后解封）、逐例预测/原始失败、评分理由、各基线汇总、可复现入口及真实评测人签收。未收到独立提交前，本协议和开发工程检查仅记准备完成。

## 只读参考接入检查

2026-10-20新增 `scripts/check_matter_independent_submission.py`。它只读输入与既有来源包，输出代码和计数，不输出问题或评测人内容，不冻结、不预测、不调用模型、不发布。引用检查复用 `load_pack` 原件/片段完整性校验，题目指纹复用既有 `question_fingerprint` 的NFKC、去空白及大小写归一化。

此检查是项目v2之后的源码增量，使用时需拉取 `feat/real-matter-closure` 最新源码；已下载的v2 ZIP保持原封存内容和哈希，不宣称包含这次新增入口。

评测人填写模板后，将状态改为 `SUBMITTED_FOR_REFERENCE_REVIEW`，补充声明、目标实现的完整提交号、来源包 `manifest.json` 的SHA256及案例组。`topic`对应实际咨询界面选择；`variants`必须归入同一原始组。每条 `exact_reference_locators` 是对象，含source_id、segment_id、locator、原文quote和original_sha256，URL索引须与之相符。只有声明的项目范围边界可改用 `reference_basis:declared_scope_boundary`、绑定 `scope_sha256` 并保持官方引用为空，不能将项目边界包装成官方政策原文。

```powershell
.\.venv\Scripts\python.exe scripts/check_matter_independent_submission.py --submission evaluation/real-matter-closure/independent-submission.template.json --expected-commit 20a87385efdadcecb57b3ad4f2d8e4152c0e9308 --receipt .runtime/reference-intake-check.json
```

上例明确检查项目v2的实现提交；评测其他版本时须先选定其完整提交号。当前空模板应退出2并报缺少评测人、来源绑定及案例组，不能为获得通过而自行补造独立案例。检查拒绝引用错配、明显个人标识、精确开发题重复、跨组归一化重复及已开始预测后再接入参考。技术字段齐备时也只返回 `TECHNICAL_BINDING_READY_ATTRIBUTION_AND_FREEZE_STILL_REQUIRED`，所有独立性认证、真人归属核查和冻结标记仍为false；同义改写是否独立、答案语义是否正确、当前政策适用性仍需实际外部复核。

其中“已开始预测”的拒绝依据是提交文件声明的计数和冻结字段，脚本没有核查平台的全部历史运行，不能证明声明真实。回执的预测/模型计数0指本检查器没有执行这些动作；参考的真实形成时间和独立性还须用外部记录证明。
