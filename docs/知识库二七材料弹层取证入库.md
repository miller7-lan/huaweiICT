# 二七区换领指南材料弹层取证入库

本页记录三段材料说明初次入库阶段。后续已补入[事项编码与时限说明](知识库二七指南时限说明与事项编码.md)，当前修订及统计以该接续记录为准；本页18项回执和两版材料包继续作为历史保留。

2026-10-18，Codex AI接续[指南首轮观察](知识库二七政务指南渲染观察.md)，从同一公开页面实际打开居民身份证材料行的三个说明弹层，并保存完整浏览器可访问性文字及一张材料依据截图。本轮新增1条待核取证记录、3段原文；这是一份代理制作的浏览器取证包，不是政府下载文件或正常HTTP取得的指南正文。

来源：[河南政务服务门户二七区申领居民身份证（换领）](https://www.hnzwfw.gov.cn/portal/guide/9BA34BC110B96284D26CE82456A51500?region=410103000000)。地区、实施主体及本地换领变体与首轮一致，未选择异地变体，未登录、提交申请或新增接口身份。普通HTTP此前只取得前端空壳，本轮没有再次请求该入口或受拒来源。

## 本轮读到什么

| 位置 | 实际文字 | 可确认范围及限制 |
| --- | --- | --- |
| 填报须知 | 换领身份证需要提供原身份证 | 与材料表居民身份证原件1份相互对应；未说明户口簿与告知承诺的关系 |
| 受理标准 | 内容真实 | 弹层仅这一句，不能自行补成身份核验、有效期或其他材料的完整标准 |
| 材料依据 | 引用居民身份证法第十一条完整文字，含领取新证时必须交回原证 | 领取交回与申请时提供分别保留；完整条文也含其他换领、补领及迁移情形，不因此扩大试点分支 |

因此，新增证据明确了本页要求原身份证的文字出处；仍不能证明所有到期换领均无条件免交户口簿。旧基层指南与2021/2022告知承诺材料关系、页面更新日、法定时限单位、减免字段和网办条件继续待核。未从取证日推定公布日或施行日，没有据此修改30题参考答案。

## 如何入库

新来源 `ERQI-RENEWAL-PORTAL-RENDERED` 保持自动采集关闭。文种是 `rendered_service_guide_observation`，采集类型为 `public_browser_accessibility_capture`，保存格式明确为代理制作的ZIP取证包。包内含首轮DOM快照、三份弹层文字、材料依据JPEG截图和逐文件哈希清单。片段逐字取自弹层正文，标明“浏览器取证待核”；没有把截图、文字转成伪造的HTTP页面。

初始保存时图片文件名扩展名与真实JPEG字节不符。现按JPEG文件头更正包内文件名与媒体类型，图片字节和三段原文保持；首版包与修订 `rev-d382504b7d780462a6fadad5` 留作历史，当前修订为 `rev-d35d070e36d4b86acfee6d71`。原始截图经实际显示及图像解码检查，1280×720像素。取证包和完整来源正文只在本机私有目录与完整备份中保存。

该记录保持 `pending_review`，`scope_confirmed=false`、`conflict=true`，公布和施行日期未知，没有人工复核或业务批准。[共享目录](../data/knowledge/candidate-catalog.json)显式导出采集类型与包格式，让团队能区分官方HTTP原件和浏览器观察。当前49来源、45归档记录（其中1条浏览器取证记录）、150历史修订、313当前片段、322个单元提案；不能把归档记录或备份载荷数量当成独立现行政策数量。
