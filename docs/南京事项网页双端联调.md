## 本阶段行为

- 群众明确选择适用条件，未知条件触发澄清；填写姓名、证件号、电话不在表单范围内。
- 九类规则主题和旧证跨文档推导显示原文、完整上下文、来源日期及知识版本。省外材料、监护材料作为例外上下文展示，不累加到省内主分支。
- 一次性交接码供工作人员接收同一会话。工作人员看到会话原条件和原版本，须明确确认；新咨询表单的未确认条件不覆盖交接条件。其他账户不能读取该会话。
- 刷新、重新登录以及进程重启后，持久会话和工程交接状态仍可读取。进程重启使原登录会话失效，需重新登录。
- 维护者暂停来源后，当前和历史答复均停止；切换旧工程版本不能绕过暂停。浏览器实测暂停后手动恢复来源并切回演化版。此为受控故障注入，不代表政府网站实际撤回文件。
- 旧证推导展示三条输入关系，其中流程顺序明确标记为种子前提，不作为法律原文引用。跨文档结果仍为开发推导、待业务复核。

## 启动与身份

从仓库根目录执行；准备命令只创建新活动，拒绝覆盖现有账户和数据：

```powershell
.\.venv\Scripts\python.exe scripts/prepare_matter_web.py --auth local-engineering
.\.venv\Scripts\python.exe -m gov_mcp.matter_web --runtime .runtime/real-matter-closure/matter-web-stage04 --port 8783
```

浏览器访问 `http://127.0.0.1:8783`。本机私有登录资料位于该活动下的 `login-credentials.json`，不得提交或共享；该目录使用当前用户及SYSTEM权限。账户密码以PBKDF2摘要验证，服务器逐次复核账户状态和角色。浏览器会话使用HttpOnly/SameSite Cookie及CSRF校验，身份不由请求中的角色字段决定；页面和接口仅绑定回环地址。

接入现有Nexent身份服务时，须另外准备新活动并显式传入 `--auth nexent --role-map <可信角色映射文件>`，同时指定新的 `--runtime`。账户角色从服务端tenant/user映射解析，无身份服务时停止，不自动切换本地账户。该模式的真实联调尚未完成。当前服务用于本机工程演示，不据此宣称已完成生产部署验收。
