## 本机使用

以下命令在仓库根目录执行。初始化命令仅登记现有线索、复制已校验归档；换机缺原件或旧M2预览库时不会自动下载或伪造资料。首次运行前安装可选PDF依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-knowledge.lock
.\.venv\Scripts\python.exe scripts\prepare_knowledge.py
.\scripts\start_knowledge_update.ps1
```

已运行时不要重复启动。状态和停止命令：

```powershell
.\.venv\Scripts\python.exe -m gov_mcp.knowledge_cli --runtime .runtime/knowledge-update status
.\scripts\stop_knowledge_update.ps1
```

服务日志、进程信息和来源配置位于私有`.runtime/knowledge-update`目录。当前已另行注册当前用户登录及每5分钟检查任务；启动脚本本身不自动登记OS任务。人工停止会设置暂停标记，防止定时恢复重新拉起服务；人工启动明确解除暂停。更新程序的临时停止使用`stop_knowledge_update.ps1 -ForRestart`。进程检查、任务登记/移除及限制见[本机自动恢复说明](知识库本机自动恢复说明.md)。

本轮已执行`prepare_knowledge_mcp.py`，因此监督进程还会启动8773的只读MCP，使用独立私有令牌和身份映射，供Docker内Nexent经`host.docker.internal`访问。仅存在知识库维护CLI有写权限；MCP通过SQLite只读连接查询。重建连接与复查命令如下：

