## 本机使用

以下命令在仓库根目录执行。初始化命令仅登记现有线索、复制已校验归档；换机缺原件或旧M2预览库时不会自动下载或伪造资料。首次运行前安装可选PDF依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-knowledge.lock
.\.venv\Scripts\python.exe scripts\prepare_knowledge.py
.\scripts\start_knowledge_update.ps1
```

已运行时不要重复启动。状态和停止命令：

```powershell
.\.venv\Scripts\python.exe -m gov_mcp.knowledge_cli --runtime .runtime/knowledge-update status
.\scripts\stop_knowledge_update.ps1
```
