## 6. Nexent 原生运行三道题（需额度）

每题是一次完整的原生运行，内部会有多次模型调用（开题、最多三份草稿、收尾），有 120 秒和 8 次模型启动的上限，不重试。

```powershell
.\.venv\Scripts\python.exe scripts/frozen_flow_native.py run "<一道应答复的跨文档题>"
.\.venv\Scripts\python.exe scripts/frozen_flow_native.py run "<一道曾因年份或数字核验失败的题>"
.\.venv\Scripts\python.exe scripts/frozen_flow_native.py run "<一道应停止的题，如含“现在”>"
```

**通过标准**：

- `passed` 为 true；
- 工具顺序以 `govkb_flow_open` 开头，后接 1 到 3 次 `govkb_flow_submit`；应停止的那题只有 `govkb_flow_open`；
- 最终答复的结论、引文与服务端任务文件（`.runtime/frozen-flow-20261114/flow-tasks/` 下对应任务的 `final`）一致，没有多出事实；
- 第二题如果第一份草稿没过，能看到一次 `revise` 后再提交。

**同时做一次一致性对照**：同一道题用命令行跑一遍（`run_frozen_qa.py ask --flow --live`），比较结果类型是否相同。模型生成有波动，草稿文字可以不同，但应停止的题两边都必须停。
**截图**：Nexent 调试界面里的工具调用过程和最终答复，各一张，留作材料。
**上传**：`evidence/frozen-flow-20261114/native-run-*.json`（先看一眼，里面有问题和最终答复文本，开发题可以传，正式评测题不传）；一致性对照写进执行报告。
