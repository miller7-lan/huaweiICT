## C8. 组织新的效果评测

必须区分三组：

操作顺序：

4. 如果有多人评分，先独立完成，之后才合议；保留原始评分与分歧。
5. 题目、参考、配置或代码改变后重新建立一个清楚标记的版本，不能覆盖旧结果。

至少分开报告：

| 指标 | 分母与注意事项 |
| --- | --- |
| 应答复题可接受/正确率 | 所有应答复题；错误停止与执行失败不静默剔除 |

不能只报告“回答了多少题”，也不能用总评分次数代替独立题数。未完成的语义或原生项目保持待验证，不包装成已具备业务准确率。

## 三人必须使用的同一套接口约定

以下是**建议新增的 V2 约定**，不是声称仓库已有这些文件或 API。若同学的新实现已有等价结构，先复用并形成对应表。

由 B 先提交 `docs/implementation/crossdoc-v2-contract.md`，A 和 C 确认字段与示例，再冻结为 `crossdoc-v2-contract-1`。共用结构放在 B 负责的 `src/gov_mcp/frozen_qa_contracts_v2.py`，不要三人各写一份。

| 对象 | 至少包含 |
| --- | --- |
| EvidenceSnapshotV2 | task_id、corpus_sha256、按 evidence_id 查找的累计证据；每条含 source_id、locator、原文与 text_sha256 |
| DraftV2 | task_id、action、claims、missing_items、next_queries、reason_code |
| ClaimV2 | claim_id、结论原文、evidence_ids；需要时包含候选事实字段、引文片段和推导信息 |
| CheckResultV2 | recommendation、issues、missing_items、next_queries、claim_results、verification_status |
| TaskResultV2 | 服务端 decision、轮次和预算、最终对象或待处理事项、渲染文本、检查范围和版本 |

- `action` 为 `answer/retrieve_more/clarify/stop`。
- `recommendation` 是 B 的核验建议；**A 的后端结合权限、来源控制和剩余预算决定最终动作**。
- 后端决策采用 `VERIFIED/RETRIEVE_MORE/REPAIR_REQUIRED/CLARIFY/STOP/EXECUTION_FAILED`。其中 `CLARIFY` 明确表示需要用户补充适用条件，不冒充证据不足或已作答。
- `issues` 每项明确关联 claim_id、evidence_id（适用时）、错误码和具体原因。
- `verification_status` 区分已完成的检查、未覆盖的检查、unknown 和服务错误；不能把“只通过引用和数字检查”称作全部语义正确。
- `VERIFIED` 仅表示通过本实例已声明的必需检查，不等于现行政策有效、正式业务批准或完整语义真值。
- `RETRIEVE_MORE/REPAIR_REQUIRED` 不产生可交付的业务答案；`CLARIFY` 只产生澄清问题；`STOP` 只交付停止说明；`EXECUTION_FAILED` 只交付运行未完成说明。
- 原问题、语料版本和当前来源控制由 A 固定。模型自称“范围允许”或“检查通过”不能覆盖后端判断。
- **额外修复最多一轮**：可以包含一次定向补查、一次草稿修订、一次重核验；不一定每轮都需要补查。刷新、重试、并发请求和重启不能重置这一预算。
- B 的 `check_draft_v2(draft, snapshot, policy)`、`assess_stop_v2(draft, snapshot, policy)` 不直接调用模型或网络、不改任务状态；外部语义评估由 A 的显式适配器提供并标记来源。
- 最终答案从已核验结论渲染；如新增事实，必须重新核验，不能在最后自由增加内容。

**旧路径保留策略：**优先新增 V2 模块和脚本，保留旧 `frozen_qa.ask()/verify()`、旧 `METHODS` 和旧 A/B 结果。不得为了插入第三种方法而破坏原两方法盲评配对逻辑。

| 阶段 | A | B | C | 进入下一阶段的条件 |

| G1 可并行开发 | 做任务状态、证据表、预算及接线 | 做纯核验模块、停止复核及模块测试 | 写验收夹具和集成测试框架 | 文件归属清楚，接口样例能解析 |

| G3 原生验收 | 运行新草稿并保留真实轨迹 | 查看真实核验输入与输出 | 比较 CLI/原生、新旧草稿和预算 | 实际运行能完成目标流程 |
