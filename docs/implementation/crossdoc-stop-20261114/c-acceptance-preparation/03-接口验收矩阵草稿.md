## 拟议契约检查

| 对象 | 预期至少包含 | C 的检查 |
|---|---|---|
| EvidenceSnapshotV2 | task_id、corpus_sha256、evidence_id、source_id、locator、原文、text_sha256 | ID 稳定，来源和任务版本绑定，拒绝其他任务或非法来源 |
| DraftV2 | task_id、action、claims、missing_items、next_queries、reason_code | action 范围 answer/retrieve_more/clarify/stop，缺口可追溯 |
| ClaimV2 | claim_id、文本、evidence_ids；必要时事实、引用和推导字段 | ID 唯一、逐项支持、数字属性/单位/条件绑定 |
| CheckResultV2 | recommendation、issues、missing_items、next_queries、claim_results、verification_status | 问题绑定 claim/evidence；区分通过、未覆盖、unknown、error |
| TaskResultV2 | 服务端 decision、轮次预算、对象或待处理项、渲染文本、范围与版本 | 后端综合限制作决策，最终文本不新增未核验事实 |

建议纯函数 `check_draft_v2(draft, snapshot, policy)` 和 `assess_stop_v2(draft, snapshot, policy)`：不调用网络、不改变任务状态。语义适配器结果须标明来源。准确字段类型、枚举、具体错误码、输入输出样例及版本号均待 B 提交与确认，不在此自行冻结。
