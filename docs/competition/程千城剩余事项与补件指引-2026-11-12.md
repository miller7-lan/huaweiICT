## 私有文件版本检查

新增标准库脚本只读本地文件，核对冻结整件散列。候选文件散列匹配后才检查单元条数；Word散列匹配后检查ZIP与正文XML结构。输出仅含状态，不打印本地路径、题目、候选或个人答案，不执行模型、生成替代候选或授权发放。

```bash
python scripts/check_cheng_closeout_inputs.py
```

尚未提供附件时输出 `AWAITING_PRIVATE_INPUTS`，退出码3。已有附件时在本地运行：

```bash
python scripts/check_cheng_closeout_inputs.py --method-b /path/to/private/unit-candidates.json --r11-body /path/to/private/body-r11.docx --r11-appendix /path/to/private/appendix-r11.docx
```

全部版本与结构匹配时退出码0；已提供文件的版本不符或结构错误时退出码2。`VERSION_MISMATCH` 可能是另一个有效版本，需要联系队长核对，不直接认定损坏。即使版本通过，方法B发放条件、实际处理及r11通读也仍需分别完成。附件说明需人工检查；脚本没有替代这一步。
