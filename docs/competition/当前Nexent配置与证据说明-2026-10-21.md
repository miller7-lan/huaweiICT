4. 主控深度 0：`govkb_crossdoc_state` → `govkb_crossdoc_finalize` → `final_answer`，原样交付工具 JSON。

### 2. 来源与知识状态

知识载体为已有 Worker、归档来源、租约任务及隔离候选库，没有绑定 Nexent 原生知识库 ID。两份真实 HTML 各保留第一项完整条款、解释标题和完整解释段落，共六段。每份完整视图超过 1800 字符即阻断，避免平台观察截断丢失中间正文。

旧资料为 2024 济源公安转载，新资料为 2026 河南省公安厅解读，详见[共享样本定义](../../data/knowledge/update-test-pairs/henan-id-time.json)。这是不同 URL 后继资料候选；页面与 URL 日期、施行日期分别处理。来源仍 `current_applicability=unknown`，不继承旧批准。候选必须保留自然日/工作日、适用对象、受理至领证期间、考试时期和绿色通道等限制。

### 3. 实际调用与成功范围

真实心跳先看到旧归档基线，脚本再登记新归档，Worker 自然到期检查间隔为 60.175 秒，观测十六个不同心跳样本。实际顺序为：

`Skill → state → 整理get(old) / get(new) / submit → state → 核验get(old) / get(new) / review → state → finish`。

两子 Agent 均在深度 1 实际提交。成功轮云端阶段 16.453 秒，模型启动八次（主控二、整理三、核验三），候选一条、正式版本零，重复提交、重复核验、工具阻断均零，最终 JSON 与持久回执一致。末轮可见主控输入 13,602、输出 272 tokens；总用量和金额未知，Jev 与英译均零。

[result.json](../../evidence/agent-autonomy-repair-20261020-a6/result.json)保存十三项真实验收与候选，[summary.json](../../evidence/agent-autonomy-repair-20261020-a6/summary.json)保存全部修复账本与范围，[preservation-check.json](../../evidence/agent-autonomy-repair-20261020-a6/preservation-check.json)保存资产及退出状态。成功后预算关闭，实验 Worker 与 8784 辅助服务停止，没有追加调用。

这条证据证明归档到达回放下的发现、调度、提取与核验，不证明官网实时政策变化、正式法律效力、长期常驻更新或发布。模型备注中“仅时限条款被取代”没有独立证明法律效力，原始措辞保留供人工复核。
