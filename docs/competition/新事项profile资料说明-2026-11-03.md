# 新事项profile资料与适配说明

建议事项为“北京市京籍居民申领临时身份证”，与现有北京普通换领实例区分。依据[北京市政府办理指南](https://www.beijing.gov.cn/fuwu/bmfw/bmzt/sfz/blzn/201806/t20180622_1857522.html)，本轮已在线读到2025-03-04页面，页面标有归档提示；原件字节SHA未在本轮重算。

该页面说明在申领、换领、补领身份证期间急需用证可申请临时证；材料为领取凭证纸质版，未满16岁另有监护人申请及身份证原件要求。地点限定为设有临时证窗口的派出所或分局户政大厅；页面表述办理时间为两个工作小时、每证10元、有效期三个月。以上作为该归档页内容核对，不转为今天个案承诺。
