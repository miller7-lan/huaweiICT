## 7.3 知识库信息

当前可运行问答使用MCP服务管理的冻结语料，河南7份原件对应581个检索单元；南京和河南固定情境的本体推理链分别读取各自的来源绑定包。自由提问的检索由字面评分完成，核验由MCP工具执行。

工程已提供按来源导出Markdown的工具，每个文件保留来源网址、原件散列、修订和定位标题，便于后续导入原生知识库。导出工具中给出的知识库名称是拟建名称，不证明平台索引已经存在。当前没有Nexent原生知识库导入、切片、嵌入模型绑定或检索对照的完成回执，不能填写成“已接入原生知识库”。

后续需要先确认嵌入模型及其调用范围，再创建知识库、上传7份导出文件、完成处理并绑定检索角色，读回文件与索引配置，检查精确引用定位是否保留。原生索引与字面检索的对照应使用同一冻结资料；更换检索实现后需要重新冻结被测版本。原件或大段文本再分发仍按材料使用边界核定。

素材与证据：[知识库导出工具](../../../scripts/export_frozen_knowledge.py)、[自由提问入口说明](../自由提问入口与评测运行说明-2026-10-30.md)。

## 7.7 同步提交文件说明

同步材料分为平台配置、Skill、MCP工程和知识材料。Agent JSON和原始平台导出ZIP对应各自日期的快照，Python工程包按当前代码另行构建；两者不能仅凭放在同一目录就视为同一版本。工程包的生成与完整性核验不代替新环境导入和真实业务执行。

| 类别 | 交付内容 | 交付前核对 |
| --- | --- | --- |
| 平台配置 | 南京、河南已有Agent JSON及原始平台导出ZIP | 文件散列、平台版本、角色和工具依赖；是否包含所述演示链 |
| Skill | 在用Skill及模板、事项规格 | 与对应接线和运行证据一致；没有遗留占位符 |
| MCP | 本体查询、冻结问答服务及依赖源码、环境与启动说明 | 专用鉴权、所需私有资料说明、版本和暂停门保留 |
| 知识材料 | 来源清单、必要的定位与散列；拟导出的7份Markdown | 使用与再分发范围确认，未完成原生导入的如实注明 |
| 工程包 | 按需生成的公开工程ZIP与校验清单、许可 | 排除凭据、账号、运行库、个人回答与独立参考答案 |
