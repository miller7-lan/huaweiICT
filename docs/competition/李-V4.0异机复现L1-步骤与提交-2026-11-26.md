## 三、步骤

以下命令都在 **PowerShell** 中执行。`<私下文件目录>` 换成你放两份文件的文件夹，例如 `D:\l1-files`。

### 第 1 步：取得同一提交

```powershell
mkdir D:\l1-v40 ; Set-Location D:\l1-v40
git clone https://github.com/miller7-lan/huaweiICT.git ICT-repro-v40
Set-Location ICT-repro-v40
git switch claude/blissful-knuth-5d407o
git checkout 6d55635
git status --short
```

**应该看到：** 最后一条命令**没有任何输出**。有输出就停下，把输出交给队长。

### 第 2 步：准备 Python 环境

```powershell
$env:PYTHONUTF8 = "1"
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -c "import mcp, sys; print(sys.version)"
```

**应该看到：** 安装结束没有红色的 `ERROR`；最后一条打印出 Python 版本（3.11 或更高）。没有 `py` 命令时，把 `py -3.12` 换成 `python`。

### 第 3 步：跑测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_claim_binding.py tests/test_evaluation_tools_audit.py tests/test_regional_scope.py tests/test_frozen_qa_flow_v3.py tests/test_frozen_qa_flow_server.py tests/test_frozen_flow_native.py tests/test_flow_v3_review_pack.py tests/test_flow_v3_preflight.py tests/test_crossdoc_native_wiring.py tests/test_frozen_qa.py tests/test_frozen_retrieval.py tests/test_extract_fact_cards.py tests/test_reproduction_tools.py
```

**通过标准：** 最后一行为 `328 passed`（后面跟 `1 warning` 也算通过）。

### 第 4 步：核对私下文件，放入原件，构建语料

```powershell
Get-FileHash <私下文件目录>\originals-v40.zip -Algorithm SHA256
Get-FileHash <私下文件目录>\new24-records.jsonl -Algorithm SHA256
```

两个散列必须分别等于第一节表格里的值。不一致说明文件传坏了，重新向队长要，**不要继续**。

```powershell
.\.venv\Scripts\python.exe scripts/pack_frozen_originals.py unpack <私下文件目录>\originals-v40.zip
.\.venv\Scripts\python.exe scripts/build_frozen_corpus.py --offline --catalog-titles --output-runtime .runtime/repro-593
```

**通过标准：** 第二条命令最后打印一行，其中：

```
"unit_count": 593, "corpus_sha256": "5e30a8d4e2239be4b52c5585bb456a2ac7f431f1f959295f28a1ba4b22eb7e05"
```

注意：`corpus.json` 文件本身的散列每次构建都不同，因为里面记了构建时间。**只比上面这个 `corpus_sha256`。**

### 第 5 步：生成指纹并与原机器比较

`<日期>` 写成 8 位数字，例如 `20261128`。

```powershell
.\.venv\Scripts\python.exe scripts/reproduction_fingerprint.py make `
  --corpus .runtime/repro-593/corpus.json `
  --questions evaluation/crossdoc-refactor-20261113/fresh-questions.json `
              evaluation/crossdoc-refactor-20261113/retrieval-probes.json `
              evaluation/independent-20261030/pilot/dev-pilot-questions.json `
  --records <私下文件目录>\new24-records.jsonl `
  --output evidence/l1-peer-v40-li-<日期>.json

.\.venv\Scripts\python.exe scripts/reproduction_fingerprint.py compare evidence/l1-linux-v40-20261126.json evidence/l1-peer-v40-li-<日期>.json
```

**通过标准：** 第二条命令输出

```
{
 "same": true,
 "differ": []
}
```

并且新生成的 `evidence/l1-peer-v40-li-<日期>.json` 里，`"fingerprint"` 为 `b50ffc5b0b8cb8906ffa5a1ce411685632ff98a8b875ccb5b15f11cdafcc662e`。

`same` 为 `false` 时，`differ` 会列出哪一部分不同：语料、模块源码、哪组题的哪一道，或是草稿回放。原样记下交回，**不要改任何东西**。

### 第 6 步：写确认文件和运行记录

在 `evidence/` 下新建两个文本文件（UTF-8）。

**`evidence/l1-peer-v40-li-<日期>-确认.md`**：由你本人填写，Agent 不能代填。

```

被测提交：6d55635
第 3 步测试：<例如 328 passed, 1 warning>

未完成或异常：<没有就写“无”>
```

**`evidence/l1-peer-v40-li-<日期>-记录.txt`**：把第 3、4、5 步每条命令输出的**最后几行**原样粘进去，每段前写上步骤号。

如果某行带有本机用户名或文件夹路径（例如 `C:\Users\xxx\...`），就把那段路径改成 `<本机路径>`，其余内容不改。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| `py` 不是命令 | 用 `python`；若版本低于 3.11，先装 3.12 |
| `pip install` 很慢或失败 | 加国内镜像：`... pip install -r requirements.lock -i https://pypi.tuna.tsinghua.edu.cn/simple`；仍失败就把错误最后 20 行交回 |
| 第 1 步 `git status --short` 有输出 | 不要继续，把输出交给队长；不要自己 `git checkout .` 掩盖 |
| 第 3 步不是 `328 passed` | 把失败的测试名和最后 30 行交回；不改代码 |
| `unpack` 报散列不一致 | 文件传坏了，重新要文件 |
| 第 4 步 `corpus_sha256` 不同 | 把整行输出交回，同时确认第 1 步提交号和 `git status` 都对 |
| 第 5 步 `same: false` | 原样交回 `differ`；这同样是有效结果 |
| 中文乱码 | 确认已执行 `$env:PYTHONUTF8 = "1"`，重新开 PowerShell 后要再执行一次 |
