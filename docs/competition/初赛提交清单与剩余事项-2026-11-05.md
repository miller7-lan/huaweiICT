## 十二、拿到新结果后如何重打

只在内容真的变化时重打，旧版本保留不覆盖，下一版用`20261112-r13`或实际日期：

```powershell
# 1 先在WPS里另存修订后的正文和附录到 artifacts/material-review-<标签>/，导出PDF确认页数
# 2 代码有改动才重打代码包
./.venv/Scripts/python.exe scripts/build_complete_source_package.py --stamp <标签>
# 3 队内审阅包（--official-pages 填正文实际页数）
./.venv/Scripts/python.exe scripts/build_material_review_bundle.py --stamp <标签> --code-stamp <标签> --official-pages <页数>
# 4 最终上传包
./.venv/Scripts/python.exe scripts/build_submission_upload.py --stamp <标签>
```
