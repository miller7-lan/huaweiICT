## 原因定位

`src/gov_mcp/frozen_qa_flow_v3.py:138-147`，`_document_number_key()`：

```python
return f"{match['issuer'][-2:]}〔{match['year']}〕{match['number']}号"
```

`财综`与`豫财综`均被压成 `财综〔2007〕34号`。

第150-175行 `mask_quoted_document_numbers()` 据此认为文号相同，在数字核验副本中将其mask；展示仍使用原草稿，因此错误文号进入最终答案。
