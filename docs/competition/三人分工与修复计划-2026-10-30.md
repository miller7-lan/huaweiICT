### 干净环境复现命令（李嘉杰）

```powershell
git clone https://github.com/miller7-lan/huaweiICT.git
cd huaweiICT
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
.\.venv\Scripts\python.exe scripts\build_competition_package.py
.\.venv\Scripts\python.exe scripts\build_competition_package.py --verify-only
```

把 `artifacts\competition-20261021\ict-topic3-public-engineering-20261021.zip` 解压到一个**新目录**，在该目录执行下面的命令。`$py` 换成克隆目录下 `.venv\Scripts\python.exe` 的绝对路径；设置 `PYTHONPATH` 是为了让测试跑解压出来的源码：

```powershell
$py = "D:\work\huaweiICT\.venv\Scripts\python.exe"
$env:PYTHONPATH = "$PWD\src;$PWD"
& $py scripts\build_competition_package.py
& $py -m pytest -q tests
```

10月30日核查时：包内重建通过，测试 354 项通过、15 项跳过；跳过的 15 项依赖私有原件，属于预期。之后按[复现与交付说明](复现与交付说明-2026-10-21.md)用 `scripts\deploy.ps1` 部署 Nexent，再在 Nexent 界面导入 `artifacts/competition-20261021/nexent-ontology-crossdoc-native-export.zip` 和 `artifacts/competition-20261022/nexent-henan-multimodal-native-export.zip`。没有模型 API 和本项目的 MCP 服务时，工具连接失败、不能对话都属预期，做到"配置导入并截图"即可，原生运行由陈子炫补跑。部署要拉取 Docker 镜像；如果网络只能访问 GitHub，就停在这一步，并写进回执。

## GitHub 协作方式

- 程千城和李嘉杰 fork 仓库，在自己的分支修改，再向 `main` 发 PR，由陈子炫审阅合并。不熟悉 PR 的话，把文件发给陈子炫代为提交。
- 每个 PR 只改自己负责的文件：程千城改 `evaluation/independent-20261030/` 下的题目与冻结文件、`records-程千城.md` 和自己的复核文档；李嘉杰改 `docs/competition/` 下的回执、交互方案、截图，以及 `screening.md`、`records-李嘉杰.md`。源码 `src/`、`scripts/` 和 Skill 只由陈子炫修改。
- 生成的 ZIP、`.runtime`、`.venv`、模板原件和参考答案都不要提交。
- 遇到问题开 GitHub Issue，写清命令、报错原文并附截图。
