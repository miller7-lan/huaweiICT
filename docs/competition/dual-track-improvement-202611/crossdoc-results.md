## 指标定义与空值

- 完整正确率：所有必答事实正确且覆盖、无严重事实错/无据结论的题数 / 预定应答题数；部分作答不计完整。
- 关键事实覆盖率：正确表达且条件完整的已覆盖必答事实数 / 冻结必答事实总数；同时给宏平均。
- 引文支撑率：原文、来源版本及定位真正支持的结论数 / 所有展示的事实结论数；后端标题和摘录另分层，不用逐字引用率替代。
- 误停止率：应答却停止题数 / 应答题数；错误回答率同时报错答/全部题与错答/实际答复，防止用停止掩盖错误。
- 用量：模型请求、Nexent启动、缓存命中/未命中输入token、输出token、总墙钟、计费币种/价格日期分别记录。模型报错与重试都进成本。
