## 留出与预先标准

1. 历史30题与24题均只作开发诊断，保存原题、参考、输出和成绩；不以重跑后的成绩覆盖。
2. 本会话已读代码及诊断，不在此自行出题并宣称独立。新24题由未接触本轮方法开发的隔离出题环境/人员只读原件生成，题面与逐事实参考分离；8比较、4时间、4推断、8应停。没有合格新题时状态保持“未建立”。既有出题说明可复用，禁止复制旧题换措辞。
3. 在第一次运行前冻结题/参考/原件/语料/代码/提示词/种子和价格版本。开发者先审核属于开发者人工审核；不满足现有formal独立性条件时，如实标development，不改开关造正式评测。
4. 原三路为普通RAG、单次受控、冻结V3。新增反馈方案与冻结V3配对，最多四路：1+1+3+3=8次/题，24题理论192次；次序按题固定随机。四路同模型、非思考、温度、输出上限、输入语料与相同问题；报告不同检索/修复预算带来的额外成本，并增加等调用预算子表。
5. **候选合并标准，先冻结再测**：16道应答题完整正确至少多2题；关键事实覆盖率与引文支撑率均不下降；错误回答不增加；8道应停题不得新增越界答复；隐私/权限/确认/来源/版本/暂停检查零严重退化。误停止单独统计，不能靠部分答复冒充完整正确。
6. 调用和token报告绝对量与差值，费用/耗时增加>25%须由本人判断收益是否值得；缺样、服务失败、超预算、无法判断及分歧均保留。小样本不能推断总体显著性。留出只评一次；失败后如再开发，另建新留出。
