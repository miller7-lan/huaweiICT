## 实际离线运行

在与历史一致的593单元语料上，两个版本各抽取一次。V1脚本散列、语料单元散列、卡片散列及全部原始卡片均匹配历史存证；V2结果另存私有目录。此为已知失败样本开发回放，非独立留出、真实模型实验或新版人工评分。

| 机械指标 | V1 | V2候选 |
| --- | ---: | ---: |
| 卡片总数 | 2,139 | 2,137 |
| 时长卡片 | 73 | 53 |
| 次数/年龄卡片 | 20 | 38 |
| 表格单元格卡片 | 888 | 888 |
| 字符片段不匹配 | 0 | 0 |
| 按冻结cells顺序核对的单元格/字符区间不一致 | 90 | 0 |
| 重复card_id的额外记录数 | 47 | 0 |

这说明“字符片段都存在”不足以保证单元格定位正确。V1对全行使用首次find会导致串列，甚至多个单元格共用一个ID；V2只从指定地址对应的完整字段取区间。重复ID消除是该定位修复的结果，不是删除重复来源或丢弃888个单元格。

原63项中只有11、13、14、55、56这5项产生结构变化，其余58项内容保持。原本人严格正确15/63的结果继续有效于V1，不能把5项机械修复直接加到分子形成新版正确率。V2新人工判定为0。

新旧单次本地抽取耗时约0.139秒、0.143秒，属于一次运行的观察，不能用来宣传性能提升或稳定性。新增模型调用、输入/输出token、API费用均为0。没有改变来源、权限、暂停或人工批准门。
