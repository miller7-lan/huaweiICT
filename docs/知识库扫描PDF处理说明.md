# 扫描PDF处理说明

2026-10-16。本机已接入可选的Windows本地OCR。它负责生成有页码、原件指纹和识别来源的待复核文本，不填写政策效力、业务结论或真人签字。

## 实际证据

[三份扫描附件处理记录](../evidence/knowledge-update/henan-scan-ocr.json)包括省厅直接链接的2021便民措施8页、2020废止通知2页、2021废止通知2页。三份原件先正常取得，再经普通采集器复查及实际Windows OCR入库；12页均按可见页面渲染并由Codex AI查看。原件、机器原始文本和检索用衍生文本一起进入备份。

[后台采集进程实测](../evidence/knowledge-update/background-ocr-check.json)另有5项通过：由常驻`knowledge-worker`领取真实任务、正常HTTP 200复查、实际执行OCR、原件及修订不重复增长、来源新鲜度恢复。它与同步引导命令分别记录，不据此宣称已观察完整自然日/周。

2021措施（豫公〔2021〕16号）第5页第二项涉及换领/补领省内通办，第5至6页第三项涉及办理周期从40自然日压缩至30日；第4页盖章和第8页印发为2021-03-25。2026修改通知涉及该文件第四项旅馆许可，不能扩展成身份证条款一并废止，也不能仅凭未被该通知修改就保证当前全部有效。第10、13题AI参考答案已补充这份直接附件，仍保留现行关系与二七区执行缺口。

另外两份通知分别为豫公通〔2020〕122号、〔2021〕108号，各废止5件非本试点文件，已排除试点回答。三份HTML入口仅含附件链接，已作为入口而非额外政策正文排除；对应PDF单独留档和监测。此时共20份归档、123段当前片段（109段HTML选择、12段机器OCR、2段既有AI视觉转录），12份最新候选被排除，正式发布仍为0。

## 识别与约束

配置精确来源时显式加入：

```json
"pdf_ocr": {"engine": "windows.media.ocr", "language": "zh-Hans-CN"}
```

没有该配置时，扫描件仍拒收；有文本层PDF优先使用文本层。OCR目前只支持Windows及已安装的`zh-Hans-CN`识别语言，依赖系统自带Windows PowerShell和WinRT，不发送扫描件到外部识别服务，也不自动安装语言包。API依据见[Microsoft OcrEngine文档](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine.recognizeasync?view=winrt-26100)。Linux、语言不可用、加密或超限文件会显示失败，不能宣称所有部署环境均支持。

- 原件限5MiB；普通文本层PDF最多100页，OCR最多20页。图像最终最长边不超过2400像素，输出页序、页数和输入SHA256必须吻合。
- 原生识别子进程限90秒，外层PDF处理限150秒；OCR任务租约10分钟，防止正常处理期间被另一个采集进程接管。普通文本层解析仍限30秒。
- 识别结果没有置信分数，记录`confidence_available=false`和`requires_visual_review=true`。每页最多16000字符、800行；疑似完整证件号码（含空格和全角字符）拒收。此检查不等于已经覆盖所有个人信息类型。
- 机器原始结果保存在原件对应修订的`source_observation.pdf_extraction.raw_ocr_pages`；片段只移除中文字符之间的空格用于检索，算法名、原始页文本和尺寸均保留，不自动修正字形、条号和日期。
- 文本定位明确为`PDF第N页（OCR待核对）`。仍先进入待复核状态，现有business发布闸门保持有效，不将OCR成功当作正式业务核定。

实际发现OCR可将2015识别成“20巧”，对盖章日期和二、三序号也有遗漏，所以页码和原图必须同时保存。这些错误没有被静默改写或自动转成生效日期。

## 页面顺序

本批PDF存在印刷拼版：MediaBox可同时含两页，而CropBox指定读者实际看到的一页。例如2021措施PDF第5页可见的是印刷页5，不应把整张拼版内的页4也拼入同一条款。原生识别遵守文件页序及可见CropBox，视觉复核使用：

```powershell
pdftoppm -cropbox -r 100 -png input.pdf private-output/page
```

每页MediaBox/CropBox和渲染指纹见实际记录。Windows桌面DPI可能影响渲染尺寸，因此解码时再做一次像素限额；不单凭渲染选项判断尺寸。Python子进程可能继承PowerShell 7的模块搜索路径，OCR脚本从Windows PowerShell自己的安装目录加载工具模块。

## 维护入口及剩余工作

首次接入使用`scripts/intake_henan_sources.py`和`scripts/finalize_henan_scans.py --enable-monitoring`；后者只接受已检查指纹、直接可见附件链接和全套渲染页，已有文档时拒绝重复引导。后续由持久任务按每日周期复查，访问仍执行robots、公开IP、TLS、跳转和限速检查。

当前是三个精确附件的自动复查，不代表已实现任意新PDF链接的自动登记。下一步将受信来源中新出现的合法PDF链接接到来源/父文档绑定、限额、去重、采集、OCR和待复核链路；未知域名或非规范性资料仍需单独筛查。六个月调整原始依据、当前本地材料关系、正式业务评测及两端启用也保持未完成。
