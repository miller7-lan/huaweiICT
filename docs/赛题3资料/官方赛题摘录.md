归档日期：2026-10-13（Asia/Shanghai）。题目：**基于华为 ModelEngine Nexent 打造可进化决策智能体**。

来源：[华为人才在线官方赛事页面](https://e.huawei.com/cn/talent/#/ict/innovation-details?zoneCode=027425&zoneId=98269700&compId=85132021&divisionName=%E4%B8%AD%E5%9B%BD%E5%8C%BA&type=C002&isCollectGender=N&enrollmentDeadline=2026-11-30%2023%3A59%3A59&compTotalApplicantCount=2493)。赛题背景、任务及开发资料由用户提供正文，并与本轮实际读取的官方浏览器页面核对；赛程、评分、材料和模板链接来自官方页面。本文为摘录和整理，不是官方附件原件。

## 赛题背景（用户提供并与官网核对的原文）

医疗、金融、先进制造、政务等行业沉淀海量多模态异构存量数据，大量数据资产缺少统一认知能力，难以支撑复杂跨文档推理、决策追溯；同时行业普遍存在标注稀缺的低资源场景，知识体系更新迭代快，传统固定知识库难以适配动态业务标准。请参赛队伍构建领域资产认知智能体，实现行业数据价值激活与智能化业务编排。

## 任务要求（用户提供并与官网核对的原文）

- 面向医疗、金融、制造、政务任一或多个行业场景，搭建多模态异构数据资产认知智能体，实现对文本、表格、图文等多元行业数据的统一识别、理解与资产标识。
- 设计低资源场景下领域知识图谱本体半自动化构建方案，实现本体持续动态更新，并支持与对应行业规范、标准体系对齐。
- 深度集成 Nexent 的 MCP 协议与 Skills 编排能力，打造“检索-推理”双驱动协同智能体执行流。
- 挖掘行业沉睡存量数据资产，实现跨文档多跳知识推理、决策链路可溯源；同时提炼通用业务逻辑，沉淀可复用、可快速部署的 Skill 工作流模板。
- 智能体基于 Nexent 平台可运行。
