## 2. 已有边界与数值限制

[共享解析器](../../src/gov_mcp/json_output.py) 能拒绝顶层和嵌套重复键、`NaN`、`Infinity`、溢出到无穷的数值、数组根和 Markdown 代码围栏。`StrictOutput` 能拒绝额外字段、缺失字段、布尔冒充整数及整数冒充布尔；校验返回原候选，不删字段或修补答案。现有检查还区分结构合格与事实正确，Schema 通过不等于业务审批通过。

JSON 小数目前解析为 Python 二进制 `float`，有精度边界，例如 `1e-9999→0.0`，`9007199254740993.0→9007199254740992.0`；同值的无小数整数文本仍可精确保留为 Python `int`。这不是本轮发现真实成功样本已出错的证据。若未来契约需要精确金额或高精度小数，应单独约定十进制表示与校验；“不修补/不强转候选”不能解释为任意十进制文本无损。JSON Schema 的 `number` 可以接受整数，不能把这一点本身当作缺陷。
