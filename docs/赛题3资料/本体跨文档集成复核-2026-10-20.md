# 南京归档本体与跨文档推理：结构复核

本轮对应赛题的“本体半自动构建与演化”和“跨文档多跳推理”。候选已由本机两份官方原件离线生成；当前仅待审，没有激活，也没有新增模型、HTTP 或原生运行。

## 本次待确认的结构

- 新类型 `IntervalComparison`：同起点、同工作日口径的区间比较。
- 新关系 `Matter -> compares_coverage -> IntervalComparison`，限定南京市居民身份证换领的历史归档预览。
- 关系包含有类型与依赖的三步执行计划：`c1` 依户籍分支计算常规等待区间；`u1` 依赖 `c1`，与未超期旧证剩余区间取交集；`j1` 依赖前两步进行比较。
- `20`、`5` 由周期原文提取；`22` 只是演示用的虚构剩余工作日区间，已经假定同一起点与口径，不做日期或日历换算。
- 南京旧证事项到南京换领事项的映射仅用于这次工程预览；不引入北京网办关系，不确认现行业务适用性。

省外虚构情境得到来源描述的常规区间 `20 + 5 = 25`，旧证区间为 `min(25, 22) = 22`，比较结果为 `false`，表示不能建立全周期覆盖。区间足够时结果仍为 `unknown`，不保证实际领证或全程可用；不推断实际缺证天数。
