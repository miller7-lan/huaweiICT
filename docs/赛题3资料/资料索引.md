## 采集与校验

项目脚本 `scripts/collect_topic3_references.py` 使用标准库下载网页并从固定 Git 对象导出资料。运行该脚本会刷新在线教程快照和其 manifest；如需保留本轮快照，先复制资料目录。它不会安装或部署 Nexent，不读取账号密码，不接入业务资料。

本轮核对了 10 个网页均成功保存、175 份 Markdown 数量、源码 ZIP 的结构与 VERSION，以及 manifest 中全部文件的大小及哈希。Word 实际下载页的名称、版本和大小已读，附件仍未确认落盘；PPT 仍只有已确认的入口。没有把 HTML 外壳误计为 Word/PPT 模板。
