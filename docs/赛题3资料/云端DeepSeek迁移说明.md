## 本地模型与向量检索

新流程的默认配置已移除 Ollama 生成调用，没有自动回退到本地 Qwen。请求通过固定官方地址发送，限制输入与输出、关闭思考模式，验证 JSON、结束状态和用量；错误不会自动重试或切换模型。生成结果始终作为机器候选，不能直接发布正式业务规则。
