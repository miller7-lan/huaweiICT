以下命令是后续获得真实调用授权后使用的入口，本次没有执行：

```powershell
.\.venv\Scripts\python.exe scripts/test_jev_live.py --live
```

默认先读环境变量；缺少时仅该实测脚本可读本地私有 `.runtime/jev/official.credentials.json` 中的 `TYPESAFE_API_KEY` 字段，也可用 `--key-file` 显式指定。普通分类脚本和工作台仍读取各自运行进程的环境变量，不会自动读取这个测试文件。不要把旧 Vercel 密钥复制到官方字段；凭据互不通用。本轮未创建凭据文件或搬运旧凭据。

仅对现有解析资料分类时，`scripts/classify_topic3_data.py --provider jev` 走官方接口；该路径保持原有英译配置，因此可能同时调用 DeepSeek，应区分独立 Jev 实测与完整英译分类链。

## 预算、隐私和证据

- 独立实测仍使用固定 9 个模拟样例，正常完成为 19 次请求，含原文支持检查、分类和选项倒序检查；单实例最多 32 次 HTTP 尝试，重试也计入预算。计数不是账户级或跨进程硬预算。
- 单请求最多 16,000 UTF-8 bytes、响应最多 2 MiB、超时 30 秒；保留原有 429/5xx 至多一次短等待重试，鉴权/额度/权限失败后阻断同实例后续调用。正式分类另有更严格的配置输入预算。
- 网络连接遵循用户已有环境变量/系统代理，保留证书验证和重定向阻断；HTTP 451 映射为 `ACCESS_RESTRICTED`，阻断同实例后续 Jev 请求及无效英译。不会自动选择其他代理节点或供应商。
- 官方回执记录端点、模型、状态、耗时及返回用量，不保存密钥、原请求或错误正文。官方响应未提供金额时，费用为未知，不能把它记成零；账单以 TypeSafe 控制台为准。
- 保留资料标签、来源、人工确认、版本及暂停边界；本次不开放真实个人资料或改变来源授权。工作台仍为离线角色，两个模型开关仍关闭。
- 新离线回归只证明接口、密钥隔离、预算及失败处理正确，不证明官方账户权限、真实分类质量或费用。本次不生成伪装成真实成功的 `latest.json`。
