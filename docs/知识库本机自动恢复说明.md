## 启停与移除

在仓库根目录执行：

```powershell
# 首次注册或重新登记当前副本，并立即检查
.\scripts\register_knowledge_startup.ps1 -StartNow
# 只读检查当前归属和健康状态
.\scripts\ensure_knowledge_update.ps1 -CheckOnly
# 人工停止：写入暂停标记，定时任务也保持暂停
.\scripts\stop_knowledge_update.ps1
# 人工启动：明确解除暂停并启动
.\scripts\start_knowledge_update.ps1
# 更新程序时短暂停止，保留自动恢复能力
.\scripts\stop_knowledge_update.ps1 -ForRestart
.\scripts\start_knowledge_update.ps1
# 仅移除当前副本的恢复任务，不停止已有服务
.\scripts\register_knowledge_startup.ps1 -Unregister
```

先完成运行目录、依赖和MCP私有配置，再登记任务。换路径后应移除旧副本任务，并在新路径重新登记；任务不会自动配置Docker、Ollama或账号。这些平台服务离线时，知识库本地采集可继续，但模型问答另行显示连接失败。完整备份恢复不会复制OS任务、令牌或启动服务，换机需重新配置。
